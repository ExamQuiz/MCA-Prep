# MCA Year 2 Notes

A static, mobile-friendly study book for the **MCA Second Year (Lateral Entry)** syllabus of M.P. Bhoj (Open) University.

## Structure
- `index.html` — home
- `toc.html` — table of index (search + accordion)
- `about.html`, `author.html`
- `chapters/` — one page per unit, plus subject overviews, labs and project
- `assets/` — `style.css`, `site.js`, `config.js`

## Set up GoatCounter (visit counter)
1. Create a free site at https://www.goatcounter.com and note your code (e.g. `myname` for `myname.goatcounter.com`).
2. In GoatCounter: **Settings -> Site -> tick "Allow adding visitor counts on your website"**.
3. Open `assets/config.js` and replace `YOURCODE` with your code.

## Publish on GitHub Pages
1. Create a new public repository and upload all of these files at the repository root.
2. Repository **Settings -> Pages -> Build and deployment -> Deploy from a branch -> main / (root)**.
3. Your site will be live at `https://<username>.github.io/<repository>/`.

## Add your notes
Open any file in `chapters/` and replace the dashed "placeholder" boxes with your content.
