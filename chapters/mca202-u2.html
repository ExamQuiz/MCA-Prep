MCA 202 · Unit II

Data Analysis using R

Syllabus topics

Univariate analysis: frequency, mean, median, modeVariance, standard deviation, skewness, kurtosisBivariate analysis: correlationRegression modeling: linear and logisticMultivariate analysisGraphical representation in R: bar plot, histogram, box plotLine plot, scatter plot, lattice plotRegression lineTwo-way cross tabulation

Overview

This unit is hands-on statistics in R: describing a single variable, relating two or more variables, fitting linear and logistic regression models, and drawing the standard plots. Expect short R programs and interpretation of outputs in the exam.

Detailed notes

1. Univariate analysis

Studies one variable at a time. Frequency counts how often each value occurs. Measures of central tendency: mean (average), median (middle value, robust to outliers) and mode (most frequent; R has no built-in function, use table()).

2. Dispersion and shape

  • Variance s² = Σ(x−x̄)² / (n−1); standard deviation = √variance.
  • Skewness measures asymmetry: positive (long right tail, mean > median), negative (long left tail), zero (symmetric).
  • Kurtosis measures tail heaviness/peakedness: normal distribution has kurtosis 3 (excess 0); higher means heavy tails (leptokurtic), lower means flat (platykurtic).

3. Bivariate analysis: correlation

Pearson correlation r = cov(x,y) / (sx sy) lies between −1 and +1; it measures the strength and direction of a linear relationship. Correlation does not imply causation. Spearman’s rank correlation is used for ordinal/non-linear monotone relations.

4. Regression modeling

  • Simple linear regression: y = β0 + β1x + ε, coefficients fitted by least squares. Assumptions: linearity, independence, constant variance, normal errors. R² gives the fraction of variance explained.
  • Multiple regression: several predictors, y = β0 + β1x1 + … + βkxk.
  • Logistic regression: for a binary outcome; models log-odds: ln(p/(1−p)) = β0 + β1x, giving probability p = 1/(1+e−z). Coefficients are interpreted as changes in log-odds (eβ = odds ratio).

5. Multivariate analysis

Analyses three or more variables together: multiple regression, MANOVA, principal component analysis, factor analysis, cluster and discriminant analysis. Watch for multicollinearity (highly correlated predictors).

7. Regression line and cross tabulation

The regression line is drawn on a scatter plot with abline(lm(y ~ x)). A two-way cross tabulation (contingency table) counts observations for each combination of two categorical variables: table(a, b); prop.table() gives proportions and chisq.test() tests association.

Diagrams & examples

marks <- c(45, 67, 89, 56, 67, 72, 90, 67)
mean(marks); median(marks); var(marks); sd(marks)
names(sort(-table(marks)))[1]            # mode

hours <- c(2, 4, 6, 8, 10, 12, 14, 16)
score <- c(40, 48, 55, 62, 70, 74, 83, 90)
cor(hours, score)                        # correlation
model <- lm(score ~ hours)               # linear regression
summary(model)                           # coefficients, R-squared
plot(hours, score); abline(model)        # scatter + regression line

# Logistic regression: pass (1) / fail (0)
pass <- c(0,0,0,0,1,0,1,1)
glm(pass ~ hours, family = binomial)

# Plots and cross tabulation
hist(marks); boxplot(marks); barplot(table(c("A","B","A","C","A")))
table(gender, dept)                      # two-way table

Important questions

Q1. Differentiate between mean, median and mode.

Mean is the arithmetic average, median the middle value (robust), mode the most frequent value.

Q2. What are skewness and kurtosis?

Skewness measures asymmetry of a distribution; kurtosis measures the heaviness of its tails.

Q3. Explain linear and logistic regression.

Linear predicts a continuous value by least squares; logistic predicts the probability of a binary class using the log-odds link.

Q4. What does a correlation coefficient of −0.9 mean?

A strong negative linear relationship: as one variable increases the other tends to decrease.

Q5. Write R code for a histogram, a box plot and a scatter plot with a regression line.

hist(x), boxplot(x), plot(x,y); abline(lm(y~x)).

Quick revision

  • Central tendency: mean, median, mode. Spread: variance, SD.
  • Skewness = asymmetry; kurtosis = tails (normal = 3).
  • Pearson r in [−1, 1]; correlation ≠ causation.
  • lm() linear, glm(family=binomial) logistic.
  • Plots: barplot, hist, boxplot, plot, xyplot.
  • table() for cross tabulation.
