Introduction to AJAX

Syllabus topics

Overview

AJAX (Asynchronous JavaScript And XML) lets a web page talk to the server in the background and update only part of the page, without a full reload. This unit explains the AJAX model, the XMLHttpRequest object, synchronous and asynchronous requests, and combining AJAX with PHP for tasks such as live field validation.

Detailed notes

1. AJAX web application model

AJAX is not a language but a technique that combines: HTML/CSS (presentation), the DOM (dynamic update), JavaScript (logic), XMLHttpRequest (asynchronous communication) and data formats (XML, JSON, text).

Classic web modelAJAX model
Each action sends a request and reloads the whole pageOnly the needed data is exchanged; part of the page is updated
User waits and loses contextPage stays usable (asynchronous)
More bandwidth and server loadLess data, faster, desktop-like feel
Synchronous, click–wait–clickAn AJAX engine (JavaScript) sits between browser UI and server

Uses: Google Suggest/Maps, live search, form validation, chat, auto-refreshing feeds. Drawbacks: back-button and bookmarking issues, needs JavaScript, SEO and security (XSS) concerns.

2. Working of AJAX

  1. An event occurs on the page (click, keyup, timer).
  2. JavaScript creates an XMLHttpRequest object.
  3. It is configured with open() and sent with send().
  4. The server (PHP/ASP/JSP) processes the request.
  5. The server returns a response (text, XML or JSON).
  6. A callback function (onreadystatechange) reads the response and updates the page through the DOM.

3. Asynchronous data transfer with XMLHttpRequest

With asynchronous transfer (async = true) the script continues running while the request is processed and the callback fires when the response arrives, so the UI does not freeze.

4. Creating the XMLHttpRequest object

var xhr = new XMLHttpRequest(); works in all modern browsers.

5. XMLHttpRequest properties and methods

6. Using XMLHttpRequest in different browsers

Modern browsers (Chrome, Firefox, Safari, Edge, IE7+) support the native XMLHttpRequest. Old Internet Explorer 5/6 used ActiveX: new ActiveXObject("Microsoft.XMLHTTP"). Use feature detection: if (window.XMLHttpRequest) {…} else if (window.ActiveXObject) {…}. Newer alternative: the fetch() API.

7. Reading a file synchronously

With open("GET", "data.txt", false) the call to send() blocks until the response is complete, so no callback is needed: read xhr.responseText right after send(). It freezes the browser while waiting and is deprecated on the main thread – avoid except for demonstration.

8. Reading a file asynchronously

Use open("GET", "data.txt", true) and set onreadystatechange; process the data only when readyState == 4 && status == 200. This is the standard approach.

9. Performing tasks using XMLHttpRequest

GET sends data in the URL query string (visible, cacheable, size-limited, for retrieval): add a random parameter or timestamp to avoid cached responses. POST sends data in the body (not in the URL, larger, for changes/forms) and needs setRequestHeader("Content-type", "application/x-www-form-urlencoded"). Typical tasks: loading text/HTML into a <div>, live search suggestions, auto-complete, refreshing data periodically with setInterval(), submitting forms.

10. Integrating PHP and AJAX

The browser sends data with the request; PHP receives it in $_GET or $_POST, processes it (database, files) and echoes the answer, which becomes responseText. Always encode values with encodeURIComponent() and sanitise input on the server (htmlspecialchars, prepared statements).

11. Validating a field using AJAX and PHP

Typical case: username availability. On keyup/blur, JavaScript sends the entered value to a PHP script; PHP checks the database (or a list) and returns “available” or “taken”; JavaScript shows the message beside the field without reloading the form. Client-side validation is for convenience; server-side validation is still required.

Diagrams & examples

Asynchronous GET – load a file into a div

<div id="result">Click the button</div>
<button onclick="loadData()">Load</button>
<script>
function loadData() {
  var xhr;
  if (window.XMLHttpRequest) xhr = new XMLHttpRequest();
  else xhr = new ActiveXObject("Microsoft.XMLHTTP");   // old IE

  xhr.onreadystatechange = function () {
    if (xhr.readyState == 4 && xhr.status == 200) {
      document.getElementById("result").innerHTML = xhr.responseText;
    }
  };
  xhr.open("GET", "data.txt", true);     // true = asynchronous
  xhr.send();
}
</script>

Synchronous read (blocks):

var xhr = new XMLHttpRequest();
xhr.open("GET", "data.txt", false);   // false = synchronous
xhr.send();
alert(xhr.responseText);

Username validation with PHP (GET)

<!-- form.html -->
<input type="text" id="user" onkeyup="check(this.value)"> <span id="msg"></span>
<script>
function check(name) {
  var xhr = new XMLHttpRequest();
  xhr.onreadystatechange = function () {
    if (xhr.readyState == 4 && xhr.status == 200)
      document.getElementById("msg").innerHTML = xhr.responseText;
  };
  xhr.open("GET", "check.php?u=" + encodeURIComponent(name), true);
  xhr.send();
}
</script>
<?php
// check.php
$taken = array("admin", "root", "guest");
$u = isset($_GET['u']) ? trim($_GET['u']) : '';
if ($u === '') echo "";
elseif (in_array(strtolower($u), $taken)) echo "<span style='color:red'>Username taken</span>";
else echo "<span style='color:green'>Available</span>";
?>

Important questions

Q1. What is AJAX? Explain the AJAX web application model and how it differs from the classic model.

Asynchronous JavaScript and XML; only part of the page is updated without reload, unlike full-page reloads in the classic model.

Q2. Explain the working of AJAX with a diagram or steps.

Event, create XHR, open/send, server processes, response, callback updates the DOM.

Q3. Explain the properties and methods of the XMLHttpRequest object.

readyState (0–4), status, responseText, responseXML, onreadystatechange; open, send, setRequestHeader, abort.

Q4. Differentiate synchronous and asynchronous requests with code.

Synchronous (async=false) blocks until complete; asynchronous uses a callback when readyState is 4.

Q5. Differentiate GET and POST in AJAX.

GET puts data in the URL (limited, cacheable); POST puts it in the body and needs a Content-Type header.

Q6. Write an AJAX and PHP program to validate a username field.

Use onkeyup, XHR GET to check.php, and display the returned message.

Quick revision

  • AJAX = HTML/CSS + DOM + JavaScript + XMLHttpRequest + XML/JSON.
  • Steps: event → XHR object → open() → send() → server → callback → DOM update.
  • readyState 0–4 (4 = done); status 200 = OK.
  • open(method, url, async): true = asynchronous, false = blocks.
  • GET data in the URL; POST needs setRequestHeader.
  • PHP reads $_GET/$_POST and echoes the response; always validate on the server too.
