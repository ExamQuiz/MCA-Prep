MCA 204 · Unit I

Responsive Web Design and Introduction to Bootstrap

Syllabus topics

Responsive web designBootstrap gridBootstrap componentsBootstrap plugins

Overview

Websites are now viewed on phones, tablets, laptops and TVs. Responsive web design (RWD) makes one page adapt to every screen size. Bootstrap is the most popular front-end framework for doing this quickly, through a 12-column grid, ready-made components and JavaScript plugins.

Detailed notes

1. Responsive web design

Coined by Ethan Marcotte, RWD means a single site that responds to the user’s device (screen width, orientation, resolution) without separate mobile and desktop versions. It rests on three ideas:

  • Fluid grids – layout widths in percentages/relative units (%, em, rem, vw) rather than fixed pixels.
  • Flexible images and media – max-width:100%; height:auto; so they scale within their container.
  • CSS media queries – apply different styles at different breakpoints.

The viewport meta tag is essential on mobile: <meta name="viewport" content="width=device-width, initial-scale=1">. Approach: mobile-first (write base styles for small screens, add min-width queries for larger ones). Other tools: Flexbox, CSS Grid, responsive typography. Benefits: one codebase, better user experience and SEO, easier maintenance.

2. Introduction to Bootstrap

Bootstrap (created at Twitter, now open source) is a free HTML/CSS/JS framework for responsive, mobile-first sites. Bootstrap 5 dropped jQuery and uses plain JavaScript. Add it with CDN links (CSS in <head>, bundle JS before </body>) or download it locally. Everything sits inside a container: .container (fixed max-width per breakpoint) or .container-fluid (full width).

3. Bootstrap grid

A 12-column, flexbox-based system: a .container holds .rows and a row holds .col-* columns whose spans add up to 12 (extra columns wrap). Breakpoints and class prefixes:

PrefixBreakpointWidth
col-Extra small< 576 px
col-sm-Small≥ 576 px
col-md-Medium≥ 768 px
col-lg-Large≥ 992 px
col-xl-Extra large≥ 1200 px
col-xxl-XXL≥ 1400 px

A class applies from its breakpoint upwards; combine them (col-12 col-md-6 col-lg-4 = full width on phones, half on tablets, one-third on desktops). Features: auto-layout (col), offsets (offset-md-2), ordering (order-*), nesting a row inside a column, gutters (g-*), alignment helpers (justify-content-center, align-items-center).

4. Bootstrap components

  • Typography & utilities: headings, text-center, colours, spacing (m-3, p-2), d-flex, d-none d-md-block.
  • Buttons (btn btn-primary), alerts, badges, cards, list groups, tables (table table-striped), images (img-fluid).
  • Forms (form-control, form-check, input groups, validation states).
  • Navigation: navbar (navbar navbar-expand-lg), nav tabs/pills, breadcrumb, pagination, dropdowns.
  • Feedback & media: progress bar, spinner, toast, carousel, accordion, modal, offcanvas.

5. Bootstrap plugins

Interactive behaviour comes from JavaScript plugins, activated either through data attributes (no JS needed: data-bs-toggle, data-bs-target) or the JavaScript API (e.g. new bootstrap.Modal(el).show()). Main plugins: Modal, Dropdown, Collapse (accordion, navbar toggle), Carousel (slider), Tooltip and Popover (need Popper and manual initialisation), Scrollspy, Tab, Toast, Offcanvas, Alert. The plugins fire events such as show.bs.modal and hidden.bs.modal. Use bootstrap.bundle.min.js, which includes Popper.

<body>

  <div class="row g-3">
    <div class="col-12 col-md-6 col-lg-4"><div class="card p-3">Column 1</div></div>

Important questions

Q1. What is responsive web design? Explain its three main techniques.

Fluid grids, flexible images and media queries make one layout adapt to all screens, with the viewport meta tag on mobile.

Q2. Explain the Bootstrap grid system with an example.

12-column flexbox grid of container, row and col-* classes with breakpoints xs to xxl; e.g. col-12 col-md-6.

Q3. List and explain any five Bootstrap components.

Buttons, alerts, cards, navbar, forms, carousel, modal, dropdown, with their key classes.

Q4. What are Bootstrap plugins? How are they activated?

JavaScript components (modal, tooltip, carousel, etc.) activated through data-bs-* attributes or the JavaScript API.

Q5. Differentiate container and container-fluid.

container has fixed max-widths at breakpoints; container-fluid spans the full width.

Quick revision

  • RWD = fluid grid + flexible images + media queries; add the viewport meta tag.
  • Bootstrap = mobile-first framework; CSS + JS via CDN.
  • Grid: container → row → col-*, 12 columns; breakpoints sm 576, md 768, lg 992, xl 1200, xxl 1400.
  • Components: btn, card, navbar, form-control, table, alert, modal, carousel.
  • Plugins: data-bs-toggle / data-bs-target; use the bundle (includes Popper).
