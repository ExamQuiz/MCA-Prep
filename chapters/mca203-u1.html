MCA 203 · Unit I

General Issues and Overview of AI; Introduction to LISP

Overview

This unit answers “what is Artificial Intelligence?” – the kinds of problems AI tackles, what makes a technique an AI technique and what AI applications look like – and then introduces LISP, the classic language of symbolic AI. LISP programs on lists, conditionals, recursion and property lists are typical exam questions.

Detailed notes

1. The AI problems

Artificial Intelligence is the study of how to make computers do things at which, at the moment, people are better (Rich & Knight). Four views: acting humanly (Turing test), thinking humanly, thinking rationally and acting rationally. Typical problem areas:

  • Mundane tasks: perception (vision, speech), natural language understanding, commonsense reasoning, robot navigation.
  • Formal tasks: games (chess), mathematics, theorem proving, logic.
  • Expert tasks: medical diagnosis, engineering design, financial analysis, scientific discovery.

Surprisingly, mundane tasks are often harder than formal ones because they need huge amounts of knowledge.

2. What is an AI technique?

Intelligence requires knowledge, but knowledge is voluminous, hard to characterise accurately, constantly changing, and differs from data by being organised so that it is usable. An AI technique is a method that exploits knowledge and is represented so that: it captures generalisations, can be understood by the people who provide it, can easily be modified to correct errors and reflect changes, and can be used in many situations even if not totally accurate. Core techniques: search (systematic exploration), use of knowledge (heuristics, rules) and abstraction (separating important features).

3. Characteristics of AI applications

Symbolic (non-numeric) processing, heuristic rather than algorithmic search, reasoning with incomplete or uncertain information, knowledge-intensive operation with a separate knowledge base, ability to learn and to explain, and interactive, natural interfaces.

4. LISP: syntax and numeric functions

LISP (LISt Processing) uses atoms (symbols, numbers) and lists in fully parenthesised prefix notation: (operator arg1 arg2 …). Programs and data have the same form (S-expressions), so programs can manipulate programs. Numeric functions: + - * /, mod, rem, sqrt, expt, max, min, abs, round, truncate. Example: (+ 2 (* 3 4)) → 14. quote (or ') prevents evaluation.

6. Predicates and conditionals

Predicates return T (true) or NIL (false): atom, listp, numberp, symbolp, null, equal, eq, member, zerop, evenp, oddp, and comparisons > < = >= <=. Conditionals: if, cond (multi-way), when, unless, and logical and, or, not.

7. Input/output and local variables

Output: print, princ, format, terpri (new line). Input: read. Global assignment: setq, defvar. Local variables: let (parallel binding) and let* (sequential binding); function parameters are local too. Functions are defined with defun.

8. Iteration and recursion

Iteration: do, dotimes, dolist, loop. Recursion is the natural LISP style: a base case plus a recursive step on (cdr list).

9. Property lists and arrays

Every symbol has a property list of indicator–value pairs, used as a simple database: (setf (get 'ram 'age) 25), (get 'ram 'age) → 25, (symbol-plist 'ram), (remprop 'ram 'age). Arrays: (setq a (make-array 5)), (setf (aref a 0) 10), (aref a 0); multi-dimensional: (make-array '(3 3)).

Diagrams & examples

;; Factorial (recursion)
(defun fact (n)
  (if (<= n 1) 1 (* n (fact (- n 1)))))
(fact 5)            ; => 120

;; Fibonacci
(defun fib (n)
  (cond ((= n 0) 0) ((= n 1) 1)
        (t (+ (fib (- n 1)) (fib (- n 2))))))

;; Sum of a list
(defun sum-list (l)
  (if (null l) 0 (+ (car l) (sum-list (cdr l)))))
(sum-list '(1 2 3 4))   ; => 10

;; Iteration
(dotimes (i 3) (print i))                      ; 0 1 2
(let ((total 0)) (dolist (x '(1 2 3)) (setq total (+ total x))) total)   ; 6

;; Own member function
(defun my-member (x l)
  (cond ((null l) nil) ((equal x (car l)) l) (t (my-member x (cdr l)))))

Important questions

Q1. What is AI? Explain the AI problems.

Making computers perform tasks people do better; mundane (vision, language), formal (games, logic) and expert tasks (diagnosis).

Q2. What is an AI technique? Why is knowledge important?

A method that exploits knowledge organised so it generalises, is understandable, modifiable and widely usable; knowledge is voluminous and changing.

Q3. Differentiate car, cdr and cons with examples.

car returns the first element, cdr the rest, cons adds a new first element to a list.

Q4. Write a LISP function to find the factorial of a number.

See the fact function above using base case and recursion.

Q5. Explain property lists in LISP with an example.

Symbol-attached indicator/value pairs set with (setf (get ...)) and read with get.

Q6. Differentiate let and let*.

let binds variables in parallel; let* binds sequentially so later bindings can use earlier ones.

Quick revision

  • AI problems: mundane, formal, expert tasks. Turing test.
  • AI technique = search + knowledge + abstraction.
  • LISP: atoms and lists, prefix notation, code = data.
  • car/cdr/cons/list/append/reverse; predicates return T/NIL.
  • cond for multi-way, let/let* for locals, defun for functions.
  • Recursion: base case + cdr; plist via get/setf; arrays via make-array/aref.
