MCA 202 · Unit I

Introduction to Data Science and Big Data

Syllabus topics

Overview

This unit introduces data science – extracting knowledge from data – and the world of big data. You learn the standard project process, how to explore data, how analytics scaled from a single server to clusters, the difference between reporting and analysis, and the statistical ideas (sampling, re-sampling, inference) that all later units rely on.

Detailed notes

1. Introduction to data science

Data science combines statistics, computer science and domain knowledge to turn raw data into decisions. A data scientist asks a question, collects and cleans data, builds models and communicates the result. Applications: recommendation, fraud detection, churn prediction, healthcare, demand forecasting.

2. Data science process

  1. Set the goal – define the business question and success measure.
  2. Retrieve data – databases, files, APIs, web.
  3. Prepare data – cleaning, integration, transformation, handling missing values.
  4. Explore (EDA) – summaries and plots.
  5. Model – select variables, train, validate.
  6. Present and automate – report results and deploy (operationalize).

The process is iterative: findings at any step may send you back to an earlier one. (An equivalent lifecycle: discovery, data preparation, model planning, model building, communicating results, operationalizing.)

3. Exploratory data analysis (EDA)

EDA (John Tukey) is the first look at data to understand its shape, spot errors and outliers, find patterns and form hypotheses. Tools: summary statistics (mean, median, quartiles), histograms, box plots, scatter plots and correlation tables.

4. Big data: definition, risks and structure

Big data is data so large, fast or varied that traditional tools cannot store or process it. The 3 Vs: Volume, Velocity, Variety (often + Veracity, Value). Structure:

  • Structured – fixed schema (RDBMS tables).
  • Semi-structured – tags without rigid schema (XML, JSON, logs).
  • Unstructured – text, images, audio, video.

Risks: privacy and legal compliance, poor data quality (garbage in, garbage out), security breaches, bias, high infrastructure and skill cost, and over-reliance on correlation.

5. Web data: the original big data

Web logs and clickstreams were among the first big data sources: every page view, click, search and purchase is recorded. Web data is semi-structured and huge, which led companies like Google and Yahoo to create MapReduce/Hadoop. It supports personalisation, ad targeting and customer-journey analysis.

6. Evolution of analytic scalability

Traditional analytics pulled data into one server (limited by memory). Then came massively parallel processing (MPP) databases, grid computing, and finally MapReduce / Hadoop and cloud clusters, where computation moves to the data across many cheap commodity machines (scale-out).

7. Analytic processes and tools

Process: define problem → collect → prepare → analyse → interpret → act. Tools: spreadsheets, SQL, R, Python, SAS, SPSS, Tableau/Power BI, Hadoop, Spark.

8. Analysis versus reporting

ReportingAnalysis
Answers what happenedAnswers why and what next
Fixed, scheduled, standard formatsAd-hoc, exploratory, customised
Pushes information to usersPulls insight; needs human interpretation
DescriptiveDiagnostic, predictive, prescriptive

9. Core vs advanced analytics

Core analytics: slicing, aggregation, BI reports, dashboards, basic statistics. Advanced analytics: predictive modeling, data mining, machine learning, text and social-network analytics, optimisation and simulation.

10. Modern data analytic tools

Hadoop, Spark, Hive, Pig, NoSQL stores (MongoDB, HBase, Cassandra), R and Python libraries, and visualization tools such as Tableau and Power BI.

11. Statistical concepts

  • Sampling distribution: distribution of a statistic (e.g. the mean) over many samples. By the Central Limit Theorem the sample mean is approximately normal with standard error σ/√n for large n.
  • Re-sampling: reuse the sample to estimate variability – bootstrap (sampling with replacement), jackknife (leave-one-out), permutation tests and cross-validation.
  • Statistical inference: drawing conclusions about a population from a sample – estimation (point and confidence intervals) and hypothesis testing (null/alternative hypothesis, test statistic, p-value, Type I and II errors).

12. Introduction to data visualization

Visualization communicates patterns quickly. Choose chart by purpose: comparison (bar), trend (line), distribution (histogram, box plot), relationship (scatter), composition (pie/stacked bar). Good practice: label axes, avoid clutter and misleading scales.

Diagrams & examples

# R: quick EDA and a bootstrap estimate of the mean
x <- c(12, 15, 11, 18, 20, 14, 13, 17)
summary(x)                      # min, quartiles, median, mean, max
boot <- replicate(1000, mean(sample(x, replace = TRUE)))
sd(boot)                        # bootstrap standard error
quantile(boot, c(0.025, 0.975)) # 95% confidence interval

CLT idea: if σ = 10 and n = 25, the standard error of the sample mean is 10/√25 = 2.

Exam tip: remember the order of the data science process and give one example for each of structured, semi-structured and unstructured data.

Important questions

Q1. Explain the data science process.

Set goal, retrieve data, prepare, explore, model, present/automate – iterative in nature.

Q2. What is big data? Explain its characteristics and risks.

Data beyond traditional tools; volume, velocity, variety (+veracity, value); risks include privacy, quality and cost.

Q3. Differentiate between analysis and reporting.

Reporting describes what happened in fixed formats; analysis explains why and predicts what next.

Q4. What is bootstrapping?

A re-sampling method that draws many samples with replacement from the data to estimate the variability of a statistic.

Q5. Explain core versus advanced analytics.

Core: BI, aggregation, dashboards. Advanced: predictive modeling, machine learning, text analytics, optimisation.

Quick revision

  • Data science = statistics + computing + domain knowledge.
  • Process: goal → data → prepare → EDA → model → present.
  • Big data: 3 Vs; structured / semi / unstructured.
  • Scalability: single server → MPP → MapReduce/cloud.
  • Reporting = what; analysis = why/what next.
  • CLT, standard error σ/√n; bootstrap, jackknife; hypothesis testing and p-value.
