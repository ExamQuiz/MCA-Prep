jQuery

Overview

jQuery is a fast, small JavaScript library that makes DOM selection, event handling, animation and AJAX much shorter (“write less, do more”). The unit begins with the core JavaScript DOM objects and then covers jQuery selectors, attribute methods, traversing, manipulation, events, effects and AJAX.

Detailed notes

1. JavaScript DOM objects

  • Window: top-level browser object; alert(), confirm(), prompt(), open(), close(), setTimeout(), setInterval(), innerWidth, innerHeight.
  • History: pages visited; history.back(), forward(), go(n), length.
  • Location: current URL; properties href, protocol, hostname, port, pathname, search, hash; methods reload(), assign(url), replace(url).
  • Document: the loaded page; getElementById(), getElementsByTagName(), querySelector(), write(), createElement(), title, cookie, forms.
  • Form: document.forms[0] or by name; elements, value, checked, submit(), reset(), events onsubmit, onchange; used for validation.

2. Fundamentals of jQuery

jQuery is a cross-browser library (John Resig, 2006). Basic syntax: $(selector).action() – $ (alias of jQuery) selects elements and an action method works on them. Method chaining: $("p").css("color","red").slideUp();. Advantages: short code, cross-browser, many plugins, built-in effects and AJAX. The document-ready event makes sure the DOM is loaded: $(document).ready(function(){ … }); or the shorthand $(function(){ … });.

3. Loading and using jQuery

Include the library in <head> or before </body>, before any script that uses it: from a CDN (Google, Microsoft, jQuery CDN – cached, fast) or a local copy downloaded from jquery.com. If another library also uses $, call jQuery.noConflict().

4. Using jQuery library files

Two versions: uncompressed (development) jquery-x.y.z.js (readable, for debugging) and minified (production) jquery-x.y.z.min.js (smaller, faster). Related files: jQuery UI (widgets: datepicker, dialog, tabs), jQuery Mobile and many plugins; keep them in a js/ folder and link with <script src="js/jquery.min.js">. Use a local fallback if the CDN fails.

5. Call-back functions

A callback is a function passed as an argument and executed after the current action finishes. JavaScript statements run line by line, so with animations the next line could run before the effect ends; a callback guarantees order: $("p").hide(1000, function(){ alert("Hidden"); });. Callbacks are also used for event handlers and AJAX completion.

6. jQuery selectors

7. Methods to access HTML attributes

  • attr("name") / attr("name","value"), removeAttr(), prop() (for checked, disabled).
  • Content: text() (plain text), html() (HTML markup), val() (form value).
  • Classes/CSS: addClass(), removeClass(), toggleClass(), hasClass(), css("prop","value"); sizes: width(), height(); data().

8. Methods of traversing

Ancestors: parent(), parents(), closest(). Descendants: children(), find(). Siblings: siblings(), next(), prev(), nextAll(). Filtering: first(), last(), eq(n), filter(), not(). Looping: each().

9. jQuery manipulators

Insert inside: append(), prepend(). Insert outside: after(), before(). Remove: remove() (element and its data), empty() (children only). Others: clone(), wrap(), replaceWith(), html(), text().

10. jQuery events

Mouse: click, dblclick, mouseenter, mouseleave, hover; keyboard: keydown, keyup, keypress; form: submit, change, focus, blur; document/window: ready, resize, scroll. Attach with .click(fn) or .on("click", fn); remove with .off(); delegated events for dynamically added elements: $(parent).on("click", "child", fn). The event object offers preventDefault(), stopPropagation(), target, which; inside a handler, $(this) is the element.

11. jQuery effects

  • Show/hide: show(), hide(), toggle() (speed: "slow", "fast" or milliseconds).
  • Fading: fadeIn(), fadeOut(), fadeToggle(), fadeTo().
  • Sliding: slideDown(), slideUp(), slideToggle().
  • Custom: animate({properties}, speed, callback) (numeric CSS only); control with stop(), delay().

12. jQuery with AJAX

  • $(sel).load(url [, data] [, callback]) – loads server content into elements.
  • $.get(url, data, callback) and $.post(url, data, callback) – shorthand requests.
  • $.getJSON(url, callback) – JSON.
  • $.ajax({url, type, data, dataType, success, error, complete}) – full control.
  • $(form).serialize() builds the query string from a form.

Diagrams & examples

<script>
$(document).ready(function () {

  // Selectors + events + effects
  $("#btn").click(function () {
    $("p.note").slideToggle("slow");
  });
  $("li:even").css("background", "#eee");

  // Attributes and manipulation
  $("#img1").attr("src", "new.png");
  $("ul").append("<li>New item</li>");
  $("#box").addClass("highlight").fadeIn(500);

  // Callback after animation
  $("#panel").hide(1000, function () { alert("Panel hidden"); });

  // Traversing
  $("li").first().next().css("color", "red");
  $("li").each(function (i) { $(this).text((i + 1) + ". " + $(this).text()); });

  // Delegated event for dynamic elements
  $("#list").on("click", "li", function () { $(this).toggleClass("done"); });

  // Custom animation
  $("#ball").animate({ left: "250px", opacity: 0.5 }, 1500);
});
</script>

jQuery AJAX examples

// load(): put server content into a div
$("#result").load("data.txt");

// $.get(): username check with PHP
$("#user").keyup(function () {
  $.get("check.php", { u: $(this).val() }, function (data) {
    $("#msg").html(data);
  });
});

// $.post(): submit a form
$("#myform").submit(function (e) {
  e.preventDefault();
  $.post("save.php", $(this).serialize(), function (resp) { alert(resp); });
});

// $.ajax(): full control with JSON
$.ajax({
  url: "students.php", type: "GET", data: { id: 1 }, dataType: "json",
  success: function (s) { $("#out").text(s.name + " - " + s.marks); },
  error: function () { alert("Request failed"); }
});

Important questions

Q1. Explain the Window, History, Location, Document and Form objects of the JavaScript DOM.

Describe each with its main properties and methods, e.g. history.back(), location.href, document.getElementById(), form.submit().

Q2. What is jQuery? Explain its advantages and how to load it.

A JavaScript library for DOM, events, effects and AJAX; load from a CDN or a local file before use; syntax $(selector).action().

Q3. What is a callback function in jQuery? Give an example.

A function run after an action completes, e.g. $('p').hide(1000, function(){alert('done');}).

Q4. Explain jQuery selectors with examples.

Element, #id, .class, attribute, descendant/child and filters like :first, :even.

Q5. Differentiate append(), prepend(), after() and before().

append/prepend insert inside an element at end/start; after/before insert outside, following/preceding it.

Q6. Explain jQuery effects.

show/hide/toggle, fade*, slide* and animate() with speed and callback.

Q7. Explain jQuery AJAX methods with examples.

load(), $.get(), $.post(), $.getJSON() and $.ajax() with success and error callbacks.

Quick revision

  • DOM objects: window, history, location, document, forms.
  • jQuery: $(selector).action(); $(document).ready(); chaining.
  • Load from CDN or a local .js (min.js for production).
  • Callback = function run after an action finishes.
  • Selectors: tag, #id, .class, [attr], :first/:even.
  • attr/prop/val/text/html/css; parent/children/find/siblings/next.
  • append/prepend (inside), after/before (outside), remove/empty.
  • Events: click, hover, keyup, submit, on()/off(); effects: show/hide, fade, slide, animate.
  • AJAX: load, $.get, $.post, $.getJSON, $.ajax.
