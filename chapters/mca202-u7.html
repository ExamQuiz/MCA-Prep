Clustering and Classification

Overview

This unit covers one unsupervised method (clustering with k-means) and two supervised classifiers (decision trees and Naïve Bayes). Numerical problems on k-means, entropy/information gain and Bayes’ theorem are common.

Detailed notes

1. Overview of clustering

Clustering groups objects so that those in the same cluster are similar and those in different clusters are dissimilar, with no predefined labels (unsupervised). Similarity uses a distance measure, usually Euclidean d = √Σ(xi−yi)²; also Manhattan and cosine.

2. K-means: use cases and method

Use cases: customer segmentation, image compression, document grouping, anomaly detection, preprocessing. Algorithm:

  1. Choose k and select k initial centroids.
  2. Assign each point to its nearest centroid.
  3. Update each centroid to the mean of its points.
  4. Repeat 2–3 until assignments stop changing (convergence).

3. Determining the number of clusters

  • Elbow method: plot within-cluster sum of squares (WSS) against k; choose the “elbow” where improvement flattens.
  • Silhouette score (−1 to 1; higher is better) and the gap statistic; or domain knowledge/business need.

4. Diagnostics

Check whether clusters are meaningful: WSS and between-cluster distance, cluster sizes (very small ones may be outliers), silhouette values, and stability across different initial centroids and subsets. Examine centroids and profiles to interpret each cluster; check whether scaling of variables distorts distances.

5. Reasons to choose and cautions

Why choose: simple, fast, scalable, easy to interpret. Cautions: must specify k; sensitive to initial centroids (run several times, e.g. k-means++); sensitive to outliers and to variable scale (standardise); works best for numeric data and roughly spherical, similar-sized clusters; finds local optimum only; categorical data needs k-modes.

6. Classification and decision trees

Classification assigns a class label using a model learned from labelled training data. A decision tree is a flowchart-like tree: internal nodes test an attribute, branches are outcomes, leaves are class labels.

7. General algorithm of a decision tree

  1. Start with all training data at the root.
  2. Choose the best attribute to split on (by a purity measure).
  3. Create a branch for each outcome and partition the data.
  4. Repeat recursively on each branch.
  5. Stop when a node is pure, no attributes remain, or a size/depth limit is reached; label the leaf with the majority class.

8. Decision tree algorithms

AlgorithmSplit criterionNotes
ID3Information gainCategorical attributes only
C4.5Gain ratioHandles numeric/missing values, pruning
CARTGini indexBinary splits; classification and regression

Entropy H(S) = −Σ pi log2 pi. Information gain = H(S) − Σ (|Sv|/|S|)H(Sv). Gini = 1 − Σ pi².

9. Evaluating a decision tree

Use a confusion matrix on test data: accuracy = (TP+TN)/total, precision = TP/(TP+FP), recall = TP/(TP+FN), F1. Use train/test split or k-fold cross-validation. Avoid overfitting through pruning (pre-pruning by limits, post-pruning by cutting weak branches).

10. Decision trees in R

Packages rpart (CART), party/partykit, C50; plot with rpart.plot.

11. Naïve Bayes: Bayes’ theorem

P(C|X) = P(X|C)·P(C) / P(X): posterior probability of class C given features X.

12. Naïve Bayes classifier

Assumes features are conditionally independent given the class: P(X|C) = P(x1|C)·P(x2|C)…P(xn|C). Choose the class with the highest P(C)∏P(xi|C). Fast, works well for text/spam classification and small data; the independence assumption is rarely true. Use Laplace smoothing to avoid zero probabilities.

Entropy: a node with 9 “Yes” and 5 “No”: H = −(9/14)log2(9/14) − (5/14)log2(5/14) ≈ 0.940. A pure node has H = 0; a 50:50 node has H = 1.

Naïve Bayes: P(Spam) = 0.4, P(“free”|Spam) = 0.5, P(“free”|Ham) = 0.1. Then P(Spam|“free”) = (0.5×0.4) / (0.5×0.4 + 0.1×0.6) = 0.20/0.26 ≈ 0.77.

km <- kmeans(iris[, 1:4], centers = 3, nstart = 25)
wss <- sapply(1:8, function(k) kmeans(iris[,1:4], k, nstart=10)$tot.withinss)
plot(1:8, wss, type = "b")                       # elbow plot

library(rpart); library(rpart.plot)
tree <- rpart(Species ~ ., data = iris, method = "class")
rpart.plot(tree)
pred <- predict(tree, iris, type = "class")
table(pred, iris$Species)                        # confusion matrix

library(e1071)
nb <- naiveBayes(Species ~ ., data = iris)
predict(nb, iris[1:5, ])

Important questions

Q1. Explain the k-means algorithm. What are its limitations?

Assign points to the nearest centroid and recompute means until convergence; needs k, sensitive to initial centroids, outliers and scale.

Q2. How do you determine the number of clusters?

Elbow (WSS) method, silhouette, gap statistic, domain knowledge.

Q3. Explain the decision tree algorithm with entropy and information gain.

Choose the attribute with highest information gain to split recursively until nodes are pure.

Q4. Differentiate ID3, C4.5 and CART.

ID3 uses information gain, C4.5 gain ratio with pruning and continuous attributes, CART uses Gini with binary splits.

Q5. How is a decision tree evaluated? What is overfitting?

Confusion matrix, accuracy, precision, recall, cross-validation; overfitting fits noise and is reduced by pruning.

Q6. Explain the Naïve Bayes classifier.

Applies Bayes’ theorem with a conditional independence assumption among features and picks the class with the highest posterior.

Quick revision

  • Clustering = unsupervised; k-means: assign → update means → repeat.
  • Choose k: elbow (WSS), silhouette. Scale data; run multiple starts.
  • Decision tree: split by information gain (ID3), gain ratio (C4.5), Gini (CART).
  • Entropy 0 = pure; 1 = 50:50 (two classes).
  • Evaluate: confusion matrix, accuracy, precision, recall; prune to prevent overfitting.
  • Naïve Bayes: P(C|X) ∝ P(C)∏P(xi|C); independence assumption; Laplace smoothing.
