Overview

This unit builds the foundation for modern machine learning (ML): what ML is and its limits, the mathematics behind it, regression, optimisation, preparing and normalising data, and the main families of models. It prepares you for neural networks in Unit VII.

Detailed notes

1. Introduction to ML, scope and limitations

Tom Mitchell: a program learns from experience E with respect to task T and performance measure P if its performance at T, measured by P, improves with E. ML finds patterns in data instead of following hand-coded rules. Scope: spam filtering, recommendation, speech and image recognition, fraud detection, medical diagnosis, self-driving cars, language translation. Limitations: needs large quality data; bias in data gives biased models; overfitting; poor interpretability (black box); correlation is not causation; high compute cost; poor generalisation outside training distribution.

2. Regression

Predicts a continuous value. Linear regression: h(x) = θ0 + θ1x1 + … fitted by minimising the mean squared error J(θ) = (1/2m)Σ(h(x(i)) − y(i))² using the normal equation θ = (XTX)−1XTy or gradient descent. Polynomial regression adds powers of x for curves; regularised versions (Ridge/L2, Lasso/L1) reduce overfitting; logistic regression is used for classification. Metrics: MSE, RMSE, MAE, R².

3. Probability, statistics and linear algebra for ML

  • Probability: random variables, conditional probability, Bayes’ rule, expectation, variance, Gaussian distribution.
  • Statistics: mean, variance, covariance, correlation, sampling, confidence intervals, hypothesis tests.
  • Linear algebra: vectors, matrices, dot product, matrix multiplication, transpose, inverse, eigenvalues/eigenvectors (used in PCA), norms.
  • Calculus: derivatives, partial derivatives and gradient ∇J, chain rule.

4. Convex optimisation

Training = minimising a cost function. A function is convex if the line segment between any two points on its graph lies above it – any local minimum is the global minimum (e.g. MSE for linear regression). Gradient descent: θ := θ − α∇J(θ), where α is the learning rate (too small → slow; too large → diverges). Non-convex problems (neural nets) have many local minima/saddles.

5. Data visualisation

Histograms and box plots (distribution, outliers), scatter plots (relationships), heat maps/correlation matrices (feature relations), line charts (trends), pair plots and learning curves. It guides feature selection and detects problems before modeling.

6. Hypothesis function and testing

In ML, the hypothesis function hθ(x) is the model’s mapping from input to predicted output; learning picks the best θ from the hypothesis space. In statistics, hypothesis testing checks a claim: null hypothesis H0 (no effect) vs alternative H1; compute a test statistic (t, z, χ²) and the p-value; reject H0 if p < significance level α (usually 0.05). Type I error = rejecting a true H0; Type II = accepting a false H0.

7. Data distributions

Normal (Gaussian) bell curve (mean μ, SD σ; 68-95-99.7 rule), uniform, binomial (successes in n trials), Poisson (event counts), exponential, and skewed distributions. Knowing the distribution guides model choice and transformation (e.g. log for right-skewed data).

8. Data pre-processing

Raw data is cleaned before modeling: handle missing values (delete, mean/median imputation), remove duplicates and noise, treat outliers, encode categorical variables (label, one-hot), feature scaling, feature selection/extraction (PCA), and split into training, validation and test sets (e.g. 70/15/15).

9. Data augmentation

Artificially enlarging the training set with modified copies to reduce overfitting: for images – flip, rotate, crop, scale, brightness/noise; for text – synonym replacement, back-translation; for tabular/imbalanced data – oversampling and SMOTE.

10. Normalising data sets

Min-maxx′ = (x − min)/(max − min)Range [0, 1]

Needed for distance-based and gradient-based methods (kNN, SVM, neural nets) so that large-scale features do not dominate.

11. Machine learning models

Linear/logistic regression, decision trees and random forests, k-nearest neighbours, Naïve Bayes, SVM, k-means and hierarchical clustering, PCA, neural networks and ensembles (bagging, boosting). Concepts: bias–variance trade-off (high bias = underfitting; high variance = overfitting), cross-validation and evaluation metrics (accuracy, precision, recall, F1).

12. Supervised and unsupervised learning

Also: semi-supervised (few labels) and reinforcement learning (agent learns from rewards).

Diagrams & examples

Normalisation example – data 10, 20, 30, 40, 50 (μ = 30, σ ≈ 15.8):

Min-max for x = 20:   (20 − 10)/(50 − 10) = 0.25
Z-score for x = 20:   (20 − 30)/15.8     = −0.63

Gradient descent step for J(θ) = θ², θ = 4, α = 0.1: gradient = 2θ = 8, so θ ← 4 − 0.1×8 = 3.2 (moving towards the minimum at 0).

Important questions

Q1. Define machine learning. State its scope and limitations.

Improving performance P at task T with experience E; applications are wide, limitations include data dependence, bias and overfitting.

Q2. Explain linear regression and gradient descent.

Fit a line by minimising MSE; update parameters by subtracting the learning rate times the gradient.

Q3. What is convex optimisation? Why is it useful?

Convex cost functions have a single global minimum so gradient descent is guaranteed to find it.

Q4. Explain data pre-processing and normalisation techniques.

Cleaning, imputing, encoding, splitting; min-max and z-score scaling with formulas.

Q5. Differentiate supervised and unsupervised learning.

Labelled data predicting outputs vs unlabelled data finding structure.

Q6. What is data augmentation? Give examples.

Creating modified copies of data such as flipped/rotated images or SMOTE to reduce overfitting.

Quick revision

  • ML: learn from experience E for task T measured by P.
  • Linear regression: minimise MSE; θ := θ − α∇J.
  • Convex ⇒ local min = global min.
  • p-value < 0.05 ⇒ reject H0.
  • Preprocess: missing values, outliers, encoding, scaling, split.
  • Min-max: [0,1]; z-score: mean 0, SD 1.
  • Supervised = labelled; unsupervised = unlabelled.
