MCA 201 · Unit VI

Data Mining Fundamentals

Overview

Data mining (also called Knowledge Discovery in Databases, KDD) extracts useful patterns from huge amounts of data. This unit explains why it is needed, the kinds of data it works on, what tasks (functionalities) it performs, and the issues it faces.

Detailed notes

1. Motivation and importance

Data grows explosively (“data rich but information poor”). Data mining turns data into knowledge for business (market-basket analysis, customer retention), science, fraud detection, medicine and web analysis. KDD steps: data cleaning → integration → selection → transformation → mining → pattern evaluation → knowledge presentation.

2. Data types for mining

  • Relational databases – tables queried with SQL.
  • Data warehouses – multidimensional, historical, summarised data.
  • Transactional databases – each record is a transaction with a set of items (e.g. a shopping basket).
  • Advanced systems: object-relational, spatial, temporal/time-series, text, multimedia, stream and WWW data.

3. Data mining functionalities

TaskWhat it does
Concept/class descriptionCharacterization (summary of a target class) and discrimination (comparing classes)
Association analysisFinds items that occur together, as rules X ⇒ Y with support and confidence
Classification & predictionBuilds a model from labelled data (decision tree, Bayes, neural network) to assign classes or predict numeric values
Cluster analysisGroups similar objects without predefined labels (unsupervised)
Outlier analysisFinds objects that differ from the rest (fraud detection)
Evolution analysisModels trends and regularities of objects whose behaviour changes over time

4. Association rule measures

support(X ⇒ Y) = P(X ∪ Y) = (transactions containing X and Y) / (all transactions). confidence(X ⇒ Y) = support(X ∪ Y) / support(X). A rule is strong if it meets both minimum thresholds. The Apriori algorithm finds frequent itemsets by using the property that every subset of a frequent itemset is frequent.

5. Classification of data mining systems

By kind of database (relational, transactional, spatial, etc.), by kind of knowledge (association, classification, clustering), by techniques used (statistics, machine learning, neural networks, visualization) and by application (finance, telecom, web).

6. Major issues in data mining

  • Methodology: mining different kinds of knowledge, interactive mining at multiple levels, handling noisy/incomplete data, evaluating pattern interestingness.
  • Performance: efficiency and scalability, parallel, distributed and incremental algorithms.
  • Data diversity: relational and complex data types, heterogeneous sources.
  • Social: privacy, security and misuse of discovered knowledge.

Rule: bread => milk
support    = 3/5 = 60%     (T1, T3, T4)
confidence = 3/4 = 75%     (bread appears in 4 transactions)

Classification vs clustering: classification uses labelled training data (supervised, e.g. approve/reject loan); clustering finds groups in unlabelled data (unsupervised, e.g. customer segments).

Important questions

Q1. What is data mining? Explain the KDD process.

Extraction of interesting patterns from large data; steps: cleaning, integration, selection, transformation, mining, evaluation, presentation.

Q2. Explain data mining functionalities.

Characterization/discrimination, association, classification and prediction, clustering, outlier and evolution analysis, with an example of each.

Q3. Define support and confidence.

Support is the fraction of transactions containing X∪Y; confidence is the fraction of transactions with X that also contain Y.

Q4. Differentiate classification and clustering.

Classification is supervised with predefined classes; clustering is unsupervised and discovers the groups.

Q5. What are the major issues in data mining?

Methodology, performance/scalability, diverse data types, and privacy/security concerns.

Quick revision

  • KDD: clean → integrate → select → transform → mine → evaluate → present.
  • Data: relational, warehouse, transactional (+ spatial, text, web).
  • Tasks: description, association, classification, clustering, outlier, evolution.
  • support = P(X∪Y); confidence = support(X∪Y)/support(X).
  • Issues: scalability, noisy data, privacy.
