Neural Networks and Deep Learning Basics

Overview

This unit explains how artificial neural networks are built and trained: neurons, activation functions, loss, gradient descent and backpropagation, followed by the practical tools of deep learning – initialisation, regularisation (dropout, L1/L2), batch normalisation, momentum, autoencoders and hyper-parameter tuning.

Detailed notes

1. Linearity vs non-linearity

A neuron computes a weighted sum z = w·x + b. If every layer is purely linear, any stack of layers collapses into one linear function, so the network can only learn linear decision boundaries (it cannot solve XOR). A non-linear activation between layers lets the network approximate complex functions (universal approximation).

Sigmoid derivative: σ′(z) = σ(z)(1 − σ(z)).

3. Weights and bias

Weights set the strength of each input connection; bias shifts the activation threshold (like the intercept), letting the neuron fire even when all inputs are zero. These are the parameters learned during training. Output: a = f(w·x + b).

4. Loss function

Measures the difference between prediction and target. Regression: mean squared error L = (1/n)Σ(y − ŷ)². Binary classification: binary cross-entropy L = −[y log ŷ + (1−y) log(1−ŷ)]. Multi-class: categorical cross-entropy −Σyi log ŷi. Training minimises the loss.

5. Gradient descent

Update rule w := w − η·∂L/∂w (η = learning rate). Variants: batch (all data per step: stable, slow), stochastic (SGD) (one sample: fast, noisy) and mini-batch (e.g. 32–256 samples: standard).

6. Multilayer network

A multilayer perceptron has an input layer, one or more hidden layers and an output layer, fully connected. Forward pass: a[l] = f(W[l]a[l−1] + b[l]). More layers = “deep” learning, learning hierarchical features.

7. Back propagation

Efficiently computes gradients of the loss with respect to every weight using the chain rule, from output to input. Steps: (1) forward pass to compute outputs and loss; (2) compute the output-layer error δ = ∂L/∂z; (3) propagate the error backward: δ[l] = (W[l+1]Tδ[l+1]) ⊙ f′(z[l]); (4) gradients ∂L/∂W[l] = δ[l]a[l−1]T; (5) update weights by gradient descent; repeat for many epochs.

8. Weight initialisation

All-zero weights make neurons identical (symmetry), so they learn the same thing. Use small random values scaled to layer size: Xavier/Glorot (variance 2/(nin+nout), for sigmoid/tanh) and He initialisation (variance 2/nin, for ReLU). Good initialisation speeds convergence and limits vanishing/exploding gradients. Biases are usually started at 0.

9. Training and testing

Split data into training (learn weights), validation (tune hyper-parameters, early stopping) and test (final unbiased estimate) sets. One epoch = one pass over the training data. Overfitting: low training error but high test error; underfitting: both high. Monitor the learning curves; early stopping halts when validation loss rises.

10. Unstable gradient problem

In deep networks, gradients are products of many terms: they can vanish (→ 0, early layers stop learning; typical with sigmoid/tanh) or explode (→ ∞, unstable updates). Remedies: ReLU-type activations, proper initialisation (Xavier/He), batch normalisation, gradient clipping, residual connections, and LSTM/GRU for sequences.

11. Autoencoders

Unsupervised networks trained to reconstruct their input: an encoder compresses x into a low-dimensional code (bottleneck) and a decoder reconstructs x′; loss = reconstruction error. Types: undercomplete, sparse, denoising, variational (VAE). Uses: dimensionality reduction, feature learning, denoising, anomaly detection.

12. Batch normalisation

Normalises each layer’s inputs over the mini-batch to zero mean and unit variance, then applies learnable scale γ and shift β: x̂ = (x − μB)/√(σB² + ε). Benefits: faster and more stable training, allows higher learning rates, less sensitivity to initialisation, mild regularisation.

13. Dropout

During training, randomly switch off each neuron with probability p (e.g. 0.5), preventing co-adaptation; it behaves like averaging many thinned networks. At test time all neurons are used with outputs scaled (or “inverted dropout” scales during training). Reduces overfitting.

14. L1 and L2 regularisation

Add a penalty on weights to the loss: L2 (weight decay): L + λΣw² shrinks weights smoothly; L1: L + λΣ|w| drives many weights to exactly zero (sparsity, feature selection). λ controls the strength.

15. Momentum

Accumulates a velocity of past gradients: v := βv − η∇L; w := w + v (β ≈ 0.9). It speeds movement along consistent directions, damps oscillations in ravines and helps escape shallow minima. Related optimisers: Nesterov momentum, RMSProp, Adam (momentum + adaptive learning rates).

16. Tuning hyper-parameters

Hyper-parameters are set before training: learning rate (most important), batch size, number of epochs, number of layers and units, activation, optimiser, dropout rate, λ. Methods: grid search, random search (often better), Bayesian optimisation, and manual tuning guided by the validation performance (never the test set).

# Keras: multilayer network with dropout, L2 and Adam
import tensorflow as tf
from tensorflow.keras import layers, regularizers

model = tf.keras.Sequential([
    layers.Dense(64, activation="relu", kernel_initializer="he_normal",
                 kernel_regularizer=regularizers.l2(0.001), input_shape=(20,)),
    layers.BatchNormalization(),
    layers.Dropout(0.3),
    layers.Dense(32, activation="relu"),
    layers.Dense(1, activation="sigmoid")])
model.compile(optimizer=tf.keras.optimizers.Adam(1e-3),
              loss="binary_crossentropy", metrics=["accuracy"])

Important questions

Q1. Why do we need non-linear activation functions? Explain sigmoid and ReLU.

Without them the network is just linear; sigmoid squashes to (0,1) but saturates, ReLU = max(0,z) is fast and common.

Q2. Explain the backpropagation algorithm.

Forward pass, compute loss, propagate errors backward via the chain rule, update weights by gradient descent.

Q3. What is the unstable gradient problem? How can it be reduced?

Vanishing or exploding gradients in deep nets; use ReLU, He/Xavier init, batch norm, gradient clipping.

Q4. Explain dropout and L1/L2 regularisation.

Dropout randomly disables neurons; L2 shrinks weights, L1 yields sparse weights; both reduce overfitting.

Q5. Explain gradient descent variants and momentum.

Batch, SGD and mini-batch; momentum adds a velocity term to speed convergence and reduce oscillation.

Q6. What is an autoencoder? What is batch normalisation?

Encoder–decoder network trained to reconstruct input; batch norm standardises layer inputs per mini-batch.

Q7. Which hyper-parameters are tuned and how?

Learning rate, batch size, layers, units, dropout, λ; by grid/random search using a validation set.

Quick revision

  • Neuron: a = f(w·x + b); non-linearity is essential (XOR).
  • Sigmoid (0,1), tanh (−1,1), ReLU max(0,z), softmax for multi-class.
  • Loss: MSE (regression), cross-entropy (classification).
  • w := w − η∂L/∂w; mini-batch is standard.
  • Backprop = chain rule backwards; init: Xavier (tanh), He (ReLU).
  • Vanishing/exploding gradients → ReLU, batch norm, clipping.
  • Regularise: dropout, L1 (sparse), L2 (weight decay), early stopping.
  • Momentum, Adam; tune learning rate on validation data.
