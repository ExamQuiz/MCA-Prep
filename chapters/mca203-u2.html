MCA 203 · Unit II

Problem Solving, Search and Control Strategies

Syllabus topics

Overview

Most AI problem solving is search through a space of possible states. This unit explains how to formulate a problem, the production-system architecture, blind (exhaustive) and heuristic search methods, search of AND/OR graphs, and constraint satisfaction. A* and AO* are the most-asked algorithms.

Detailed notes

1. General problem solving

Define the state space: set of states, initial state, operators/rules that move between states, and goal test. Solving = finding a path from the initial to a goal state. Example: water-jug (4 L and 3 L jugs), 8-puzzle, missionaries and cannibals, travelling salesman. Search can be judged by completeness, optimality, time and space complexity.

2. Production systems

A production system has (i) a set of production rules (condition → action), (ii) a global database / working memory and (iii) a control strategy that picks the rule to apply (and resolves conflicts). Types: monotonic (applying a rule never prevents another from applying later), partially commutative (order of rules doesn’t matter for reaching the same result) and commutative (both). Commutative systems need no backtracking.

3. Control strategies: forward and backward chaining

  • Forward chaining (data-driven): start from facts, apply rules to derive new facts until the goal is found.
  • Backward chaining (goal-driven): start from the goal, find rules whose conclusion matches it, and make their conditions sub-goals.

A good control strategy must cause motion (not be stuck) and be systematic (not repeat states).

4. Exhaustive (blind) searches

5. Heuristic search and hill climbing

A heuristic function h(n) estimates the cost from n to a goal. Hill climbing moves to the best neighbouring state and stops when none is better; it keeps no history. Problems: local maxima, plateau and ridge. Variants: simple hill climbing, steepest-ascent and stochastic; remedies: random restarts, backtracking, simulated annealing.

6. Branch and bound

Explores paths in order of cost so far, always extending the cheapest partial path; a path whose cost exceeds the best complete solution found is pruned (bounded). Guarantees an optimal solution; with an underestimate of remaining cost it becomes A*-like.

7. Best-first search and the A* algorithm

Best-first search uses an OPEN list (nodes to expand) and a CLOSED list (expanded) and always expands the node with the best evaluation value (greedy best-first uses f = h). A* uses f(n) = g(n) + h(n): g = actual cost from the start, h = estimated cost to the goal. If h is admissible (never overestimates) A* is complete and optimal; if also consistent, no node is expanded twice. Algorithm: put start on OPEN → pick the node with the lowest f → if goal, stop → else expand it, compute f for successors, update OPEN/CLOSED (keep the cheaper path if a node is reached again) → repeat.

8. AND/OR graphs

Represent problems that can be decomposed: an OR arc gives alternatives (solve any one), an AND arc requires all sub-problems to be solved. A solution is a sub-graph, not a single path.

9. Problem reduction and AO*

Problem reduction repeatedly splits a problem into easier sub-problems. AO* searches an AND/OR graph: (1) start with the initial node; (2) expand a node on the current best partial solution graph; (3) revise the cost f(n) of its ancestors, where the cost through an AND arc = sum of the successors’ costs + arc costs and through OR = minimum; (4) mark nodes solved when all (AND) or one (OR) successors are solved; repeat until the start is solved or its cost exceeds a threshold.

10. Constraint satisfaction problems (CSP)

Defined by variables, domains and constraints. Examples: map colouring, cryptarithmetic (SEND + MORE = MONEY), N-queens, scheduling. Solving: backtracking assigns variables one at a time and backs up on violation; improvements: forward checking, arc consistency, variable ordering (most constrained first) and value ordering. Cryptarithmetic uses constraint propagation: generate possible values, then guess and propagate.

Important questions

Q1. Explain production systems and their characteristics.

Rules, working memory and control strategy; monotonic, partially commutative and commutative systems.

Q2. Compare BFS and DFS.

BFS: queue, complete, optimal for unit costs, high memory; DFS: stack, low memory, not complete or optimal.

Q3. Explain the A* algorithm. What is an admissible heuristic?

Expands the node with the lowest f = g + h; admissible h never overestimates and guarantees optimality.

Q4. What are the problems of hill climbing?

Local maxima, plateau and ridge; solved by restarts, backtracking or simulated annealing.

Q5. Explain AND/OR graphs and the AO* algorithm.

Problems split into sub-problems; AO* expands the best partial solution graph and revises ancestor costs, with AND costs summed.

Q6. What is a constraint satisfaction problem? Solve a cryptarithmetic example.

Variables, domains and constraints; use propagation plus backtracking (e.g. SEND+MORE=MONEY gives M=1).

Quick revision

  • State space = states + operators + initial + goal.
  • Forward chaining = data-driven; backward = goal-driven.
  • BFS (queue, optimal), DFS (stack, small memory).
  • Hill climbing: local max, plateau, ridge.
  • A*: f = g + h, h admissible ⇒ optimal.
  • AO*: AND = sum of costs, OR = min; solution is a subgraph.
  • CSP: variables, domains, constraints; backtracking + propagation.
