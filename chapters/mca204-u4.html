MCA 204 · Unit IV

Handling XML Data using PHP and AJAX; Web Services

Syllabus topics

JavaScript properties for extracting with nodeValueAccessing XML elements by nameAccessing attribute values in XML elementsValidating XML documents in AJAX applicationsRetrieving data from a database using PHP and AJAXConsuming web services using AJAXWeb service protocols: SOAP, WSDL, UDDI, REST

Overview

This unit continues AJAX with XML data: reading XML responses with DOM properties, validating them, fetching database records with PHP, and consuming web services. It ends with the main web service protocols: SOAP, WSDL, UDDI and REST.

Detailed notes

1. JavaScript properties for extracting with nodeValue

When the server returns XML, xhr.responseXML is a DOM document. Useful node properties: nodeName (tag name), nodeType (1 element, 2 attribute, 3 text, 9 document), nodeValue, childNodes, firstChild, lastChild, parentNode, nextSibling, attributes, and textContent. Important: an element’s own nodeValue is null; its text lives in a child text node, so use element.childNodes[0].nodeValue (or firstChild.nodeValue). Whitespace between tags also creates text nodes in some browsers.

2. Accessing XML elements by name

responseXML.getElementsByTagName("title") returns a node list; use an index and .length: x[0].childNodes[0].nodeValue. Loop over the list to show all records. documentElement gives the root.

3. Accessing attribute values in XML elements

element.getAttribute("id") returns the value; element.attributes.getNamedItem("id").nodeValue or element.attributes[0].nodeValue are alternatives; hasAttribute(), setAttribute() for checks and changes.

4. Validating XML documents in AJAX applications

  • Check for success: responseXML is null if the response is not XML or not well-formed (the server must send Content-Type: text/xml); browsers may add a parsererror element.
  • Well-formedness is checked automatically by the parser. DTD/schema validity is usually checked on the server with PHP: $dom->validate() (DTD) or $dom->schemaValidate("file.xsd").
  • Always handle errors (status != 200) and sanitise data before inserting it into the page.

5. Retrieving data from a database using PHP and AJAX

Flow: user action → AJAX request with a parameter → PHP connects to MySQL (mysqli or PDO), runs a prepared statement (prevents SQL injection) → PHP outputs results as XML (with header("Content-Type: text/xml")), JSON (json_encode) or HTML → JavaScript reads the response and updates the page (e.g. a table or drop-down). Example uses: choosing a student from a list to show details, dependent drop-downs, live search.

6. Consuming web services using AJAX

A web service is a software component accessible over a network (HTTP) by other applications, using standard formats (XML/JSON). AJAX can call REST services directly (GET/POST returning JSON or XML) and can call SOAP services by posting an XML envelope. Browser limit: the same-origin policy blocks requests to another domain. Solutions: CORS (server sends Access-Control-Allow-Origin), JSONP, or a server-side proxy (PHP script on your own server that calls the service via cURL and relays the result).

7. Web service protocols

  • SOAP (Simple Object Access Protocol): XML-based messaging protocol, usually over HTTP. A message = Envelope (root) → optional Header → Body (request/response) → Fault (errors). Platform- and language-neutral, strongly typed with WSDL, supports security and transactions (WS-*) but verbose and heavy.
  • WSDL (Web Services Description Language): XML document describing a service: types (data types), message, portType (operations), binding (protocol/format) and service (endpoint address). Clients read it to know how to call the service.
  • UDDI (Universal Description, Discovery and Integration): a registry where providers publish services and requesters search for them (white, yellow, green pages).
  • REST (Representational State Transfer): an architectural style using URIs for resources and standard HTTP methods: GET (read), POST (create), PUT (update), DELETE (remove). Stateless, cacheable, lightweight; data in JSON or XML.

Diagrams & examples

Reading an XML response

<!-- students.xml (returned by server) -->
<students>
  <student id="1"><name>Asha</name><marks>82</marks></student>
  <student id="2"><name>Ravi</name><marks>74</marks></student>
</students>

// JavaScript
xhr.onreadystatechange = function () {
  if (xhr.readyState == 4 && xhr.status == 200) {
    var xml = xhr.responseXML;
    if (!xml) { alert("Not valid XML"); return; }
    var list = xml.getElementsByTagName("student");
    var out = "";
    for (var i = 0; i < list.length; i++) {
      var id   = list[i].getAttribute("id");
      var name = list[i].getElementsByTagName("name")[0].childNodes[0].nodeValue;
      var m    = list[i].getElementsByTagName("marks")[0].childNodes[0].nodeValue;
      out += id + ". " + name + " - " + m + "<br>";
    }
    document.getElementById("out").innerHTML = out;
  }
};

PHP: retrieve database rows as XML

<?php
header("Content-Type: text/xml");
$id = (int) $_GET['id'];
$db = new mysqli("localhost", "root", "", "college");
$st = $db->prepare("SELECT name, marks FROM student WHERE id = ?");
$st->bind_param("i", $id);
$st->execute();
$st->bind_result($name, $marks);
echo "<?xml version='1.0' encoding='UTF-8'?><students>";
while ($st->fetch()) {
  echo "<student><name>" . htmlspecialchars($name) . "</name><marks>$marks</marks></student>";
}
echo "</students>";
?>

Calling a REST service with AJAX

var xhr = new XMLHttpRequest();
xhr.open("GET", "https://api.example.com/users/5", true);
xhr.onload = function () {
  if (xhr.status == 200) { var user = JSON.parse(xhr.responseText); alert(user.name); }
};
xhr.send();

Important questions

Q1. How do you extract data from an XML response using nodeValue?

Get the element with getElementsByTagName and read childNodes[0].nodeValue, because the text is in a child text node.

Q2. How do you read attribute values from XML elements in JavaScript?

Use getAttribute('id') or attributes.getNamedItem('id').nodeValue.

Q3. How can XML be validated in an AJAX application?

Check responseXML is not null (well-formedness) and validate against DTD/schema on the server with PHP.

Q4. Explain how data is retrieved from a database using PHP and AJAX.

AJAX request with a parameter, PHP queries MySQL with a prepared statement and returns XML/JSON, JavaScript updates the page.

Q5. Explain SOAP, WSDL and UDDI.

SOAP is the XML messaging protocol, WSDL describes the service, UDDI is the registry to publish and find services.

Q6. Differentiate SOAP and REST.

SOAP is a heavy XML protocol with WSDL; REST is a lightweight style using URIs and HTTP verbs with JSON/XML.

Q7. What is the same-origin policy and how can it be overcome?

Browsers block cross-domain AJAX; use CORS headers, JSONP or a server-side proxy.

Quick revision

  • XML response = responseXML; text = childNodes[0].nodeValue (element nodeValue is null).
  • getElementsByTagName(), getAttribute().
  • Server sends Content-Type: text/xml; validate (DTD/XSD) on the server.
  • PHP + MySQL: prepared statement → XML/JSON output.
  • SOAP: Envelope, Header, Body, Fault. WSDL: describes. UDDI: registry.
  • REST: URIs + GET/POST/PUT/DELETE, stateless, JSON.
  • Cross-domain: CORS, JSONP, proxy.
