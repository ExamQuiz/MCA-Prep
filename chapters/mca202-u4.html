Overview

This unit introduces the Hadoop ecosystem: HDFS for storage, MapReduce for processing, HBase for random access, Hive for SQL-like queries, Spark for fast in-memory processing and Sqoop for moving data between Hadoop and relational databases.

Detailed notes

1. Hadoop overview

Apache Hadoop is an open-source framework for storing and processing very large data on clusters of commodity hardware. Core parts: HDFS (storage), MapReduce (processing) and YARN (resource management). Features: scalability, fault tolerance, low cost, data locality (move code to data).

2. RDBMS versus Hadoop

FeatureRDBMSHadoop
DataStructuredStructured, semi-structured, unstructured
SchemaSchema-on-writeSchema-on-read
ScalingVertical (bigger server)Horizontal (more nodes)
AccessInteractive, low latency, updatesBatch, high throughput, write-once read-many
CostLicensed, expensive hardwareOpen source, commodity hardware

3. HDFS: components and block replication

  • NameNode (master) – keeps metadata: namespace, file-to-block mapping.
  • DataNodes (slaves) – store blocks, send heartbeats and block reports.
  • Secondary NameNode – periodically merges the edit log with the fsimage (checkpointing); it is not a hot standby.

Files are split into large blocks (default 128 MB) and each block is replicated (default factor 3) across different DataNodes and racks (rack awareness) for fault tolerance; lost replicas are re-created automatically.

4. Introduction to MapReduce

A programming model with two functions: map (input → intermediate key/value pairs) and reduce (merges values of each key), with an automatic shuffle and sort between them. Optional combiner (local reduce) and partitioner.

5. Running algorithms using MapReduce

Common patterns: word count, grep/filtering, sorting, inverted index, join (reduce-side or map-side), matrix multiplication and iterative algorithms like PageRank and k-means (one MapReduce job per iteration).

6. HBase: architecture, HLog and HFile, replication

  • HMaster assigns regions and handles schema changes; RegionServers serve read/write requests for regions (row ranges); ZooKeeper coordinates the cluster.
  • Write path: write to HLog (write-ahead log) → MemStore (in-memory) → flushed to HFile on HDFS. HLog allows recovery after a RegionServer crash.
  • Data replication: HDFS replicates HFiles for storage durability; HBase also supports cluster-to-cluster replication of edits for disaster recovery.

7. Introduction to Hive

A data-warehouse layer on Hadoop providing HiveQL (SQL-like). Queries are translated into MapReduce/Tez/Spark jobs. The metastore stores table schemas. Suited to batch analytics, not real-time transactions.

8. Introduction to Spark

A fast cluster-computing engine that keeps data in memory using RDDs (Resilient Distributed Datasets) with lazy transformations and actions and a DAG scheduler. Up to ~100× faster than MapReduce for iterative jobs. Libraries: Spark SQL, Streaming, MLlib, GraphX. APIs in Scala, Java, Python, R.

9. Apache Sqoop

A tool to import data from relational databases (MySQL, Oracle) into HDFS/Hive/HBase and export results back, using parallel MapReduce jobs.

Important questions

Q1. Compare RDBMS and Hadoop.

Schema-on-write vs schema-on-read, vertical vs horizontal scaling, structured vs any data, interactive vs batch.

Q2. Explain HDFS architecture and block replication.

NameNode, DataNodes, Secondary NameNode; 128 MB blocks with replication factor 3 across racks.

Q3. Explain MapReduce with the word count example.

Map emits (word,1); shuffle groups by key; reduce sums counts.

Q4. Explain HBase architecture. What are HLog and HFile?

HMaster, RegionServers, ZooKeeper; HLog is the write-ahead log, HFile is the on-disk store file on HDFS.

Q5. Compare Hive and Spark. What is Sqoop used for?

Hive gives SQL over Hadoop (batch); Spark is in-memory processing; Sqoop transfers data between RDBMS and Hadoop.

Quick revision

  • Hadoop = HDFS + MapReduce + YARN.
  • HDFS: NameNode (metadata), DataNode (blocks), 128 MB, replication 3.
  • MapReduce: map → shuffle/sort → reduce (+combiner).
  • HBase: HMaster, RegionServer, ZooKeeper, HLog → MemStore → HFile.
  • Hive = SQL on Hadoop; Spark = in-memory RDD; Sqoop = import/export RDBMS.
