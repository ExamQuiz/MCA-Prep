2. Programs

Program 1: PHP program to print the reverse of any number

Aim: To write a PHP program that reads a number and prints its reverse (12345 gives 54321).

Source code

reverse.php
<?php
$result = "";
if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $n = trim($_POST["number"]);
    if (!preg_match('/^-?\d+$/', $n)) {
        $result = "Please enter a valid whole number.";
    } else {
        $num = (int)$n;
        $negative = $num < 0;
        $num = abs($num);
        $rev = 0;
        while ($num > 0) {
            $digit = $num % 10;          // last digit
            $rev = $rev * 10 + $digit;   // append it to the reversed number
            $num = intdiv($num, 10);     // drop the last digit
        }
        if ($negative) { $rev = -$rev; }
        $result = "Reverse of $n is $rev";
    }
}
?>
<!DOCTYPE html>
<html lang="en">
<head><meta charset="UTF-8"><title>Reverse a Number</title></head>
<body>
  <h2>Reverse of a number</h2>
  <form method="post" action="">
    Enter a number: <input type="text" name="number" required>
    <input type="submit" value="Reverse">
  </form>
  <p><b><?php echo htmlspecialchars($result); ?></b></p>
</body>
</html>
reverse_simple.php
<?php
// Short version using built-in string functions
$n = 12345;
echo "Number  : $n <br>";
echo "Reverse : " . strrev((string)$n);     // 54321
?>

How to run

Save in htdocs/mca206/ and open http://localhost/mca206/reverse.php.

Expected output

Input 12345 → Reverse of 12345 is 54321. Input 1200 → Reverse of 1200 is 21 (leading zeros disappear in a number). Input abc → “Please enter a valid whole number.”

How it works

  • % 10 gives the last digit; intdiv($num, 10) removes it.
  • $rev * 10 + $digit builds the reversed number one digit at a time.
  • preg_match validates the input; htmlspecialchars protects the output from HTML injection.
  • The program is a single page: the form posts to itself and PHP runs when REQUEST_METHOD is POST.

Viva questions

Q1. What is the difference between GET and POST?

GET sends data in the URL (visible, limited length); POST sends it in the request body (not shown in the URL, larger data).

Q2. What does strrev() do?

It reverses a string; it works on text, so a number must be treated as a string.

Q3. What is the use of $_SERVER['REQUEST_METHOD']?

It tells whether the page was requested with GET or POST.

Program 2: PHP script to upload a file to the server and display its details

Aim: To upload a file from a form to the server and display its name, type, size and stored location.

Source code

upload.html
<!DOCTYPE html>
<html lang="en">
<head><meta charset="UTF-8"><title>File Upload</title></head>
<body>
  <h2>Upload a file</h2>
  <!-- enctype must be multipart/form-data for file uploads -->
  <form action="upload.php" method="post" enctype="multipart/form-data">
    Select file: <input type="file" name="myfile" required>
    <input type="submit" value="Upload">
  </form>
</body>
</html>
upload.php
<?php
$dir = "uploads/";                       // folder inside the project
if (!is_dir($dir)) { mkdir($dir, 0755, true); }

if ($_SERVER["REQUEST_METHOD"] != "POST" || !isset($_FILES["myfile"])) {
    die("No file submitted.");
}
$f = $_FILES["myfile"];

if ($f["error"] !== UPLOAD_ERR_OK) {
    die("Upload failed. Error code: " . $f["error"]);
}

$allowed = array("jpg", "jpeg", "png", "gif", "pdf", "txt", "docx");
$ext = strtolower(pathinfo($f["name"], PATHINFO_EXTENSION));
if (!in_array($ext, $allowed)) { die("File type not allowed."); }
if ($f["size"] > 2 * 1024 * 1024) { die("File is too large (maximum 2 MB)."); }

// make the stored name safe and unique
$safeName = time() . "_" . preg_replace("/[^A-Za-z0-9._-]/", "_", basename($f["name"]));
$target = $dir . $safeName;

if (move_uploaded_file($f["tmp_name"], $target)) {
    echo "<h3>File uploaded successfully</h3>";
    echo "<table border='1' cellpadding='6'>";
    echo "<tr><th>Original name</th><td>" . htmlspecialchars($f["name"]) . "</td></tr>";
    echo "<tr><th>Type</th><td>" . htmlspecialchars($f["type"]) . "</td></tr>";
    echo "<tr><th>Size</th><td>" . round($f["size"] / 1024, 2) . " KB</td></tr>";
    echo "<tr><th>Temporary file</th><td>" . htmlspecialchars($f["tmp_name"]) . "</td></tr>";
    echo "<tr><th>Stored at</th><td>" . htmlspecialchars($target) . "</td></tr>";
    echo "</table>";
    if (in_array($ext, array("jpg", "jpeg", "png", "gif"))) {
        echo "<p><img src='" . htmlspecialchars($target) . "' width='200' alt='uploaded image'></p>";
    }
} else {
    echo "Could not save the file. Check the folder permissions.";
}
?>

How to run

Put both files in htdocs/mca206/, open http://localhost/mca206/upload.html, choose a file and click Upload.

Expected output

A table such as: Original name photo.png, Type image/png, Size 48.2 KB, Temporary file C:\xampp\tmp\php1A2B.tmp, Stored at uploads/1731234567_photo.png, followed by a preview of the image.

How it works

  • The form needs method="post" and enctype="multipart/form-data".
  • PHP puts file information in the superglobal $_FILES: name, type, size, tmp_name, error.
  • move_uploaded_file() moves the file from the temporary folder to the target folder.
  • Always check extension, size and error code; never trust the original file name. Upload limits are set in php.ini (upload_max_filesize, post_max_size).

Viva questions

Q1. Which superglobal holds uploaded file information?

$_FILES.

Q2. Why is enctype="multipart/form-data" required?

Without it the browser sends only the file name, not the file contents.

Q3. What does move_uploaded_file() do and why not copy()?

It safely moves a file uploaded via HTTP POST and fails for files that were not really uploaded, which prevents path tricks.

<?xml version="1.0" encoding="UTF-8"?>

  <xsl:output method="html" encoding="UTF-8"/>

    <html>
      <head>
        <title>Address Book</title>
        <style>

        </style>
      </head>
      <body>
        <h2>Address Book</h2>
        <table>
          <tr><th>ID</th><th>Name</th><th>Phone</th><th>Email</th><th>City</th><th>Pincode</th></tr>
          <xsl:for-each select="addressbook/contact">
            <xsl:sort select="name/last"/>
            <tr>
              <td><xsl:value-of select="@id"/></td>
              <td><xsl:value-of select="name/first"/><xsl:text> </xsl:text><xsl:value-of select="name/last"/></td>
              <td><xsl:value-of select="phone"/></td>
              <td><xsl:value-of select="email"/></td>
              <td><xsl:value-of select="address/city"/></td>
              <td><xsl:value-of select="address/pincode"/></td>
            </tr>
          </xsl:for-each>
        </table>
        <p>Total contacts: <xsl:value-of select="count(addressbook/contact)"/></p>
      </body>
    </html>
  </xsl:template>
</xsl:stylesheet>

How to run

Keep both files in the same folder under htdocs and open http://localhost/mca206/addressbook.xml. (Chrome blocks XSLT for file:// pages, so always use localhost; Firefox and Edge also work.) To see the raw XML tree, open the file without the xml-stylesheet line.

Expected output

The browser shows a table sorted by last name (Patel, Sharma, Verma):

ID  Name         Phone       Email                    City    Pincode
--  -----------  ----------  -----------------------  ------  -------
3   Neha Patel   9988776655  neha.patel@example.com   Ujjain  456010 
2   Ravi Sharma  9123456780  ravi.sharma@example.com  Bhopal  462016 
1   Asha Verma   9876543210  asha.verma@example.com   Indore  452001 

Total contacts: 3

How it works

  • The XML has one root element (addressbook) and repeated contact elements with an id attribute.
  • <?xml-stylesheet ...?> links the XSLT file so the browser transforms the data to HTML.
  • xsl:for-each loops over contacts, xsl:sort orders them by last name, xsl:value-of prints values, and count() gives the total.
  • Rules for well-formed XML: one root, closed and properly nested tags, quoted attributes, case-sensitive names.

Viva questions

Q1. What is a well-formed XML document?

One that follows the XML syntax rules: single root, all tags closed and nested properly, attribute values quoted.

Q2. Why do we use XSLT with XML?

XML only stores data; XSLT transforms it into HTML (or other formats) for display.

Q3. Difference between an element and an attribute?

An element is a tag with content; an attribute is a name–value pair inside the start tag, like id="1".

Program 4: XML document and database: importing and exporting XML to/from a database

Aim: To import data from an XML document into a MySQL table, and to export the table data back to an XML document using PHP.

Source code

setup.sql
CREATE DATABASE IF NOT EXISTS addressdb;
USE addressdb;

CREATE TABLE IF NOT EXISTS contacts (
  id          INT AUTO_INCREMENT PRIMARY KEY,
  first_name  VARCHAR(40),
  last_name   VARCHAR(40),
  phone       VARCHAR(15),
  email       VARCHAR(80),
  street      VARCHAR(80),
  city        VARCHAR(40),
  pincode     VARCHAR(10)
);
db.php
<?php
// db.php - common database connection
$conn = new mysqli("localhost", "root", "", "addressdb");   // host, user, password, database
if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
}
$conn->set_charset("utf8mb4");
?>
import.php
<?php
// import.php - read addressbook.xml and insert every <contact> into MySQL
require "db.php";

$xml = simplexml_load_file("addressbook.xml");
if ($xml === false) {
    die("The XML file is missing or not well-formed.");
}

$sql = "INSERT INTO contacts (first_name, last_name, phone, email, street, city, pincode)
        VALUES (?, ?, ?, ?, ?, ?, ?)";
$stmt = $conn->prepare($sql);

$count = 0;
foreach ($xml->contact as $c) {
    $first   = (string)$c->name->first;
    $last    = (string)$c->name->last;
    $phone   = (string)$c->phone;
    $email   = (string)$c->email;
    $street  = (string)$c->address->street;
    $city    = (string)$c->address->city;
    $pincode = (string)$c->address->pincode;
    $stmt->bind_param("sssssss", $first, $last, $phone, $email, $street, $city, $pincode);
    $stmt->execute();
    $count++;
}
echo "$count contact(s) imported from XML into the database.";
$stmt->close();
$conn->close();
?>
export.php
<?php
// export.php - read the contacts table and write it out as an XML document
require "db.php";

function addChild($dom, $parent, $tag, $text) {
    $el = $dom->createElement($tag);
    $el->appendChild($dom->createTextNode($text));   // text node escapes &, < and >
    $parent->appendChild($el);
    return $el;
}

$result = $conn->query("SELECT * FROM contacts ORDER BY id");

$dom = new DOMDocument("1.0", "UTF-8");
$dom->formatOutput = true;                            // indented, readable output
$root = $dom->createElement("addressbook");
$dom->appendChild($root);

while ($row = $result->fetch_assoc()) {
    $contact = $dom->createElement("contact");
    $contact->setAttribute("id", $row["id"]);

    $name = $dom->createElement("name");
    addChild($dom, $name, "first", $row["first_name"]);
    addChild($dom, $name, "last",  $row["last_name"]);
    $contact->appendChild($name);

    addChild($dom, $contact, "phone", $row["phone"]);
    addChild($dom, $contact, "email", $row["email"]);

    $address = $dom->createElement("address");
    addChild($dom, $address, "street",  $row["street"]);
    addChild($dom, $address, "city",    $row["city"]);
    addChild($dom, $address, "pincode", $row["pincode"]);
    $contact->appendChild($address);

    $root->appendChild($contact);
}

$dom->save("exported.xml");                           // also keep a copy on the server
header("Content-Type: text/xml; charset=UTF-8");      // show as XML in the browser
echo $dom->saveXML();
$conn->close();
?>

How to run

1) Start Apache and MySQL in XAMPP. 2) Open phpMyAdmin (http://localhost/phpmyadmin), go to the SQL tab and run setup.sql. 3) Keep addressbook.xml (from Program 3) in the same folder. 4) Run http://localhost/mca206/import.php, then http://localhost/mca206/export.php.

Expected output

import.php: 3 contact(s) imported from XML into the database. (the table contacts now has 3 rows). export.php: the browser shows the XML tree generated from the table: an <addressbook> root with three <contact id="1">… elements, and a file exported.xml is created on the server. Running import twice inserts duplicates.

How it works

  • Import: simplexml_load_file() loads the XML into an object; the loop reads each contact and inserts it using a prepared statement (safe against SQL injection).
  • Export: DOMDocument builds the XML tree; createTextNode() makes sure special characters such as & are escaped; formatOutput indents the result.
  • header('Content-Type: text/xml') tells the browser to treat the output as XML; it must be sent before any other output.
  • db.php keeps the connection code in one place and is included with require.

Viva questions

Q1. What is the difference between DOM and SimpleXML in PHP?

DOM gives full control to create and modify XML trees; SimpleXML is a simple object interface for reading XML.

Q2. Why use prepared statements?

They separate SQL from data, preventing SQL injection and allowing the same statement to be reused.

Q3. What is the purpose of the Content-Type header?

It tells the browser the type of data being sent, here XML instead of HTML.

Program 5: XML program for internal DTD (Document Type Definition) creation

Aim: To create an XML document that contains an internal DTD and check that the document is valid.

Source code

students.xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE students [
  <!ELEMENT students   (university, student+)>
  <!ELEMENT university (#PCDATA)>
  <!ELEMENT student    (name, roll, course, marks?)>
  <!ATTLIST student
            id     ID           #REQUIRED
            gender (M|F)        "M">
  <!ELEMENT name   (#PCDATA)>
  <!ELEMENT roll   (#PCDATA)>
  <!ELEMENT course (#PCDATA)>
  <!ELEMENT marks  (#PCDATA)>
  <!ENTITY univ "M.P. Bhoj (Open) University">
]>
<students>
  <university>&univ;</university>
  <student id="s1" gender="F">
    <name>Asha Verma</name>
    <roll>101</roll>
    <course>MCA</course>
    <marks>82</marks>
  </student>
  <student id="s2">
    <name>Ravi Sharma</name>
    <roll>102</roll>
    <course>MCA</course>
  </student>
</students>
validate.php
<?php
// validate.php - check the XML file against its internal DTD
libxml_use_internal_errors(true);          // collect errors instead of printing warnings

$dom = new DOMDocument();
$dom->load("students.xml");

if ($dom->validate()) {
    echo "students.xml is VALID (it follows its DTD).";
} else {
    echo "students.xml is NOT valid:<br>";
    foreach (libxml_get_errors() as $err) {
        echo "Line " . $err->line . ": " . htmlspecialchars(trim($err->message)) . "<br>";
    }
    libxml_clear_errors();
}
?>

How to run

Open students.xml in a validating tool: in the command line xmllint --noout --valid students.xml, or in an XML editor (Notepad++ XML Tools, Oxygen), or run http://localhost/mca206/validate.php. Browsers only check well-formedness, not the DTD.

Expected output

Valid file: xmllint --noout --valid students.xml prints nothing (no errors) and validate.php shows “students.xml is VALID”.

Invalid file: if the <roll> element of the second student is removed, validation fails with an error like:

students_invalid.xml:26: element student: validity error : Element student content does not follow the DTD, expecting (name , roll , course , marks?), got (name course )
  </student>
            ^

How it works

  • The DTD is written inside <!DOCTYPE students [ ... ]>, which makes it an internal DTD (an external one would use SYSTEM "file.dtd").
  • <!ELEMENT student (name, roll, course, marks?)>: a sequence in this order; ? makes marks optional (+ = one or more, * = zero or more).
  • <!ATTLIST> declares attributes: id is a unique ID and required; gender is an enumeration with default M.
  • <!ENTITY univ ...> defines a reusable entity, used as &univ;.
  • A valid document is well-formed and also follows its DTD.

Viva questions

Q1. What is a DTD and why is it used?

A Document Type Definition lists the allowed elements, attributes and structure, so documents can be validated.

Q2. Difference between internal and external DTD?

Internal DTD is inside the XML file; external DTD is a separate .dtd file referenced with SYSTEM or PUBLIC.

Q3. What do #PCDATA, ?, * and + mean?

Parsed character data (text); zero or one; zero or more; one or more occurrences.

Program 6: Program to change the content of a web page using AJAX

Aim: To change a part of a web page by fetching new content from the server with AJAX, without reloading the whole page.

Source code

change.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>AJAX: Change Page Content</title>
  <style>
    body { font-family: Arial, sans-serif; margin: 30px; }
    #box { border: 1px solid #888; padding: 15px; margin-top: 15px; min-height: 50px; }
  </style>
</head>
<body>
  <h2>AJAX - change content without reloading the page</h2>
  <button type="button" onclick="loadContent('content.txt')">Load text file</button>
  <button type="button" onclick="loadContent('news.html')">Load HTML fragment</button>
  <button type="button" onclick="resetBox()">Reset</button>
  <div id="box">Original content. Click a button to change me.</div>

  <script>
    function resetBox() {
      document.getElementById("box").innerHTML = "Original content. Click a button to change me.";
    }

    function loadContent(url) {
      var xhr = new XMLHttpRequest();                 // 1. create the object
      var box = document.getElementById("box");
      box.innerHTML = "Loading...";

      xhr.onreadystatechange = function () {          // 2. what to do when the state changes
        if (xhr.readyState === 4) {                   //    4 = request finished
          if (xhr.status === 200) {                   //    200 = OK
            box.innerHTML = xhr.responseText;         // 3. update only this part of the page
          } else {
            box.innerHTML = "Error " + xhr.status + ": " + xhr.statusText;
          }
        }
      };

      xhr.open("GET", url, true);                     // true = asynchronous
      xhr.send();                                     // 4. send the request
    }
  </script>
</body>
</html>
content.txt
This text was loaded from content.txt using AJAX.
The page was NOT reloaded.
news.html
<h3>Latest news</h3>
<ul>
  <li>MCA lab examination on Monday</li>
  <li>Project synopsis due next week</li>
</ul>

How to run

Keep the three files in one folder and open http://localhost/mca206/change.html. Open it through localhost; with file:// the browser blocks the request (status 0).

Expected output

Initially the box shows “Original content…”. Load text file briefly shows “Loading…” and then the text of content.txt; Load HTML fragment shows the heading and list from news.html; Reset restores the original text. The URL and the rest of the page never reload.

How it works

  • Steps: create XMLHttpRequest → set onreadystatechange → open() → send().
  • readyState goes 0→4; 4 means the response is complete. status 200 means success.
  • responseText holds the server’s reply, inserted with innerHTML.
  • Asynchronous (true) means the page stays responsive while waiting.

Viva questions

Q1. What is AJAX?

Asynchronous JavaScript And XML: a technique to exchange data with the server in the background and update parts of a page.

Q2. What are the values of readyState?

0 unsent, 1 opened, 2 headers received, 3 loading, 4 done.

Q3. Why does the program fail when opened with file://?

Browsers restrict XMLHttpRequest on local files for security; use a web server such as Apache.

Program 7: Asynchronous JavaScript and XML for a web page login process

Aim: To implement a login form that sends the username and password to the server with AJAX (POST) and shows the result without reloading the page.

Source code

login.html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>AJAX Login</title>
  <style>
    body { font-family: Arial, sans-serif; margin: 40px; }
    input { display: block; margin: 8px 0; padding: 6px; width: 220px; }
    #msg { margin-top: 12px; font-weight: bold; }
  </style>
</head>
<body>
  <h2>AJAX login</h2>
  <div id="loginForm">
    <input type="text" id="username" placeholder="Username">
    <input type="password" id="password" placeholder="Password">
    <button type="button" onclick="doLogin()">Login</button>
  </div>
  <div id="msg"></div>

  <script>
    function doLogin() {
      var u = document.getElementById("username").value.trim();
      var p = document.getElementById("password").value;
      var msg = document.getElementById("msg");

      if (u === "" || p === "") {                     // client-side check
        msg.style.color = "red";
        msg.textContent = "Please enter both username and password.";
        return;
      }

      var xhr = new XMLHttpRequest();
      xhr.onreadystatechange = function () {
        if (xhr.readyState === 4) {
          if (xhr.status === 200) {
            var r = xhr.responseText;
            if (r.indexOf("OK:") === 0) {             // login success
              msg.style.color = "green";
              msg.textContent = r.substring(3).trim();
              document.getElementById("loginForm").style.display = "none";
            } else {                                  // login failed
              msg.style.color = "red";
              msg.textContent = r.replace("ERROR:", "").trim();
            }
          } else {
            msg.style.color = "red";
            msg.textContent = "Server error: " + xhr.status;
          }
        }
      };
      xhr.open("POST", "login.php", true);
      xhr.setRequestHeader("Content-type", "application/x-www-form-urlencoded");
      xhr.send("username=" + encodeURIComponent(u) + "&password=" + encodeURIComponent(p));
    }
  </script>
</body>

login.php
<?php
// login.php - checks the credentials and sends a short text answer back to AJAX
session_start();
header("Content-Type: text/plain; charset=UTF-8");

if ($_SERVER["REQUEST_METHOD"] !== "POST") {
    http_response_code(405);
    exit("ERROR: Invalid request.");
}

$user = trim($_POST["username"] ?? "");
$pass = $_POST["password"] ?? "";

if ($user === "" || $pass === "") {
    exit("ERROR: Please fill in both fields.");
}

// Demo users. In a real project store hashed passwords in a database.
$users = array(
    "admin"   => "admin123",
    "student" => "mca2026"
);

if (isset($users[$user]) && hash_equals($users[$user], $pass)) {
    $_SESSION["user"] = $user;                    // remember the login
    echo "OK: Welcome, " . $user . "! You are logged in.";
} else {
    echo "ERROR: Invalid username or password.";
}
?>

How to run

Place login.html and login.php in the same folder and open http://localhost/mca206/login.html. Test with admin / admin123 and with a wrong password.

Expected output

Empty fields → red message “Please enter both username and password.” Wrong details → red “Invalid username or password.” Correct details (admin / admin123) → the form disappears and a green message “Welcome, admin! You are logged in.” is shown – all without a page reload.

How it works

  • POST is used so the password is not placed in the URL; Content-type: application/x-www-form-urlencoded must be set with setRequestHeader.
  • encodeURIComponent() safely encodes special characters before sending.
  • PHP reads $_POST, validates, starts a session on success and returns plain text starting with OK: or ERROR:; JavaScript decides what to display.
  • textContent (not innerHTML) shows the message, avoiding script injection. Client-side checks improve usability; the real check is on the server.
  • For real applications store passwords with password_hash() and check them with password_verify() (see the optional DB version), and use HTTPS.

Viva questions

Q1. Why use POST instead of GET for login?

GET puts the data in the URL, where it appears in history and logs; POST sends it in the request body.

Q2. What is a PHP session?

Server-side storage identified by a cookie, used to remember a user between requests (session_start(), $_SESSION).

Q3. Why must validation also be done on the server?

Client-side JavaScript can be bypassed or disabled, so the server must always verify the data.

Program 8: AJAX using JavaScript, DHTML and XMLHttpRequest to perform a GET or POST and return a result without reloading the page

Aim: To send data to the server with either the GET or POST method using the XMLHttpRequest object and display the result on the same page without reloading it.

    function calculate() {
      var a = encodeURIComponent(document.getElementById("a").value);
      var b = encodeURIComponent(document.getElementById("b").value);
      var method = document.querySelector('input[name="method"]:checked').value;
      var out = document.getElementById("result");
      var params = "a=" + a + "&b=" + b;

      var xhr = new XMLHttpRequest();
      xhr.onreadystatechange = function () {
        out.style.display = "block";                              // DHTML: show the box
        if (xhr.readyState < 4) {
          out.innerHTML = "Processing... (readyState " + xhr.readyState + ")";
        } else if (xhr.status === 200) {
          out.innerHTML = xhr.responseText;                       // result from the server
          out.style.backgroundColor = (method === "GET") ? "#e8f4ff" : "#fff4e0";   // DHTML: change style
        } else {
          out.innerHTML = "Error " + xhr.status;
        }
      };

      if (method === "GET") {
        xhr.open("GET", "calc.php?" + params + "&t=" + new Date().getTime(), true);   // t avoids caching
        xhr.send();
      } else {
        xhr.open("POST", "calc.php", true);
        xhr.setRequestHeader("Content-type", "application/x-www-form-urlencoded");
        xhr.send(params);
      }
    }
  </script>

calc.php
<?php
// calc.php - works for both GET and POST requests
$method = $_SERVER["REQUEST_METHOD"];
$src = ($method === "POST") ? $_POST : $_GET;

if (!isset($src["a"], $src["b"]) || !is_numeric($src["a"]) || !is_numeric($src["b"])) {
    echo "<b>Error:</b> please enter two valid numbers.";
    exit;
}

$a = $src["a"] + 0;
$b = $src["b"] + 0;

echo "<b>Method used:</b> $method<br>";
echo "$a + $b = " . ($a + $b) . "<br>";
echo "$a - $b = " . ($a - $b) . "<br>";
echo "$a &times; $b = " . ($a * $b) . "<br>";
echo "$a &divide; $b = " . ($b != 0 ? round($a / $b, 4) : "undefined (division by zero)") . "<br>";
echo "<small>Server time: " . date("d-m-Y H:i:s") . "</small>";
?>

How to run

Put both files in htdocs/mca206/ and open http://localhost/mca206/calc.html. Enter two numbers, choose GET or POST and click Calculate.

Expected output

For 12 and 4 with GET: a light-blue box shows Method used: GET; 12 + 4 = 16; 12 − 4 = 8; 12 × 4 = 48; 12 ÷ 4 = 3 and the server time. With POST the same result appears in a light-orange box with Method used: POST. The URL stays unchanged. Invalid input shows an error message.

How it works

  • GET: data is appended to the URL (calc.php?a=12&b=4) and send() has no body; a timestamp parameter stops the browser from caching the answer.
  • POST: the URL is plain; the data goes in send(params) and a Content-type header is required.
  • DHTML (HTML + CSS + JavaScript + DOM): the script shows the result box, writes text with innerHTML and changes its colour using style.
  • The same PHP file reads $_GET or $_POST depending on REQUEST_METHOD.

Viva questions

Q1. When do you prefer GET and when POST?

GET for retrieving or searching (safe, bookmarkable, cacheable); POST for sending forms, passwords or changing data.

Q2. What is DHTML?

Dynamic HTML: HTML, CSS and JavaScript working through the DOM to change a page after it has loaded.

Q3. Why is the third argument of open() set to true?

It makes the request asynchronous so the browser does not freeze while waiting.

4. General viva questions

Q1. What is PHP? Is it client-side or server-side?

PHP is a server-side scripting language; the server runs the code and sends only HTML to the browser.

Q2. What are superglobals? Name some.

Built-in variables available everywhere: $_GET, $_POST, $_FILES, $_SESSION, $_COOKIE, $_SERVER.

Q3. Difference between include and require?

On a missing file, include gives a warning and continues; require stops the script with a fatal error.

Q4. What is the difference between echo and print?

Both output text; echo can take several arguments and is slightly faster; print returns 1.

Q5. What is XML? Where is it used?

A markup language to store and exchange data: configuration files, RSS, web services, document formats.

Q6. What is the difference between well-formed and valid XML?

Well-formed follows syntax rules; valid is also checked against a DTD or schema.

Q7. What is a DTD? What is XSD?

DTD defines structure with non-XML syntax and no data types; XML Schema (XSD) is XML-based with data types and namespaces.

Q8. What are DOM and SAX parsers?

DOM loads the whole document as a tree in memory; SAX reads it as a stream of events with low memory use.

Q9. What does XSLT do?

Transforms an XML document into HTML, text or another XML format using templates and XPath.

Q10. What is AJAX? What are its advantages?

A technique to fetch data in the background; the page updates partially, so it is faster and smoother, with less bandwidth.

Q11. List the properties and methods of XMLHttpRequest.

readyState, status, responseText, responseXML, onreadystatechange; open(), send(), setRequestHeader(), abort().

Q12. What is the difference between synchronous and asynchronous requests?

Synchronous blocks the browser until the response arrives; asynchronous continues and calls a function when the response is ready.

Q13. Which format is more popular with AJAX today, XML or JSON?

JSON, because it is lighter and maps directly to JavaScript objects (JSON.parse()).

Q14. What is SQL injection and how do you prevent it?

Inserting malicious SQL through input; prevented with prepared statements and input validation.

Q15. What is a session and a cookie?

A cookie is stored in the browser; a session stores data on the server and links it with a cookie ID.

Q16. What is the same-origin policy?

Browsers block scripts from reading responses from another domain, protocol or port unless the server allows it (CORS).
