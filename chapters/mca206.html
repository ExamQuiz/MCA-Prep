MCA 206 (P)

💻 Advanced Web Technology Lab

Max / Min marks: 100 / 50Practical

PHP, XML, DTD and AJAX practicals.

Suggested practical list

  1. Design a PHP program to print the reverse of any number.
  2. Design a PHP script for uploading a file to the server and displaying the uploaded file's details.
  3. Create a simple XML document to display an address book.
  4. Create an XML document and database for importing and exporting an XML document into a database.
  5. Create an XML program for internal DTD (Document Type Definition) creation.
  6. Create a program to change the content of a web page using AJAX.
  7. Create a program implementing asynchronous JavaScript and XML for a webpage login process.
  8. Create a program in AJAX using JavaScript, DHTML and the XMLHttpRequest object to perform a GET or POST and return a result without reloading the HTML page.
